# 地震网格裂缝样本

本步骤把真实井和虚拟井的裂缝密度归并到地震网格，并读取同一网格 8 个角点的蚂蚁体、相干体和曲率体原始值。

## 样本合同

- 一个 CSV 文件对应一口真实井或一条虚拟井轨迹。
- CSV 每行对应一个唯一地震网格。
- 每行严格 25 列：`FractureDensity`、3 个属性各自 8 个角点值。
- 井来源只通过目录和文件名表示，CSV 内不增加井名、坐标和索引列。
- 角位编码 `000/001/010/011/100/101/110/111` 依次表示 X、Y、TIME 的低/高节点。

## 密度口径

`FractureDensity` 为网格内井点的 `PointConfidence` 加权平均裂缝密度。负样本密度按 0 参与平均；因此该值保持源 `DensityLabel` 的量纲，避免通过简单求和放大采样点数量和采样间隔的影响。

## 属性口径

- 砂砾岩使用 12.5 m XY 网格，2 ms 时间节点。
- 太古界使用外部属性道头反算的 1650×1307 个 12.5 m 网格节点和 1 ms 时间节点；道头坐标的米级取整残差不得超过 2.5 m，且每个网格节点必须有且只有一个属性道。
- 属性值在网格的 8 个节点直接读取，不做归一化、不做四邻域插值。
- 非有限值和超出正式物理范围的值写为 NaN；太古界蚂蚁体 `-1` 是有效低值，原样保留。

## 输出组织

- 砂砾岩：`优化阶段二/正式主线/output/seismic_fracture_grid_samples_sand_v1/`
- 太古界：`太古界/output/taigu_seismic_fracture_grid_samples_v1/`
- 真实井：`real_wells/<真实井>.csv`
- 虚拟井：`virtual_wells/<源真实井>/<虚拟井>.csv`
- 每口源井先写真实井，再按自然序写其 25 条虚拟井，共 26 个样本文件。
- `sample_file_manifest.csv` 记录每口井的网格行数、非零密度行数、完整角点行数和输入点行数；`source_well_selection.csv` 固定本次源井选择。

## 正式配置

- `configs/formal_sand_16x26_v1.json`：16 口砂砾岩源井，每口 1 条真实井 + 25 条虚拟井，共 416 个 CSV。
- `configs/formal_taigu_8x26_v1.json`：8 口太古界源井，每口 1 条真实井 + 25 条虚拟井，共 208 个 CSV。

运行入口：`run_formal_16x26_8x26_v1.sh`。长任务通过 tmux 启动。
