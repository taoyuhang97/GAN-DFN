## 1. 项目总目标

本项目当前正式主线固定为：

`裂缝密度样本 -> 裂缝密度体 -> 初始DFN -> 井控校正后的DFN`

当前阶段范围固定如下：

1. 当前目标层段只做矿区内 `T4-T7`，也就是沙三到沙四上这一段。
2. 当前不是做全矿区全深度，而是先完成一个 `3000m x 3000m` demo 区域内、`T4-T7` 空间中的样本体系和后续建模入口。
3. `Density` 是前半段主监督，裂缝点位不是与 `Density` 同等级的主标签。
4. 当前流程重点不是直接做 DFN，而是先把前面的样本层和密度体学习入口做对。

## 2. 已确认硬口径

### 2.1 标签口径

1. `Density` 是主监督标签。
2. 测井上的具体裂缝点位主要用于后续点位细化和最终 DFN 校正。
3. 不能把 `HasFracture` 提升为和 `Density` 同等级的主监督任务。

### 2.2 层位与分组口径

1. 当前每个地震道的层位时间，按 `T4/T5/T6/T7` 层位数据中 `xy` 最近曼哈顿距离点的时间值作为层位时间。
2. `T4` 当前暂用未平滑版本。
3. `T5/T6/T7` 优先用 2024 新版层位面。
4. 若后续补充平滑后的 `T4`，应优先替换当前 `T4`。
5. 当前地层分组固定为：
   - `T4-T6 => 沙三段`
   - `T6-T7 => 沙四段`

### 2.3 成像井分层口径

如果成像测井样本构造中的层位解释，与旧项目中成像井人工分层深度冲突，则必须以旧项目中写死的人工分层为准：

`/home/tyh/projects/petroleum/code/GAN-DFN/模型训练/优化阶段一/基于地层约束的测井裂缝预测/manual_strata_workflow/common.py`

即：

1. 成像井分层以旧项目确认好的人工分层为准。
2. 新的自动层位挂接不能覆盖这套成像井人工分层。

### 2.4 真实井与虚拟井属性口径

1. 真实井点和虚拟井点的属性都必须按真实 `X/Y/TIME` 去体数据中取值。
2. 不能贴最近地震道代替真实点位取值。
3. 井周属性不只看垂向，要同时考虑平面方向变化。
4. 平面邻域当前统一按 `12.5m` 地震道间距定义。
5. `3x3` 命名方式固定为：
   - `x1_y1` 表示中心点
   - `x0_y0` 表示 `-12.5m`
   - `x2_y2` 表示 `+12.5m`

### 2.5 采样口径

1. `0.2ms` 不是当前正式默认口径。
2. 旧项目中 `0.2ms` 只是历史实验路径，不是当前新主线的强制标准。
3. 当前正式样本应优先保留原始或近原始采样口径，除非后续专门论证重采样必要性。

### 2.6 虚拟测井口径

1. 虚拟测井是样本扩充层，不是最终成果层。
2. 虚拟测井不是新的实际井，也不是 DFN 单元。
3. 虚拟测井当前正确理解是：
   - 以单口真实井为源
   - 向它井周地震道位置生成“如果这里有井，井上裂缝会怎样”的弱监督样本
4. 单口源井的虚拟测井外推，当前不能引入其他井的信息混合进去。
5. 虚拟井 `Density` 的变化不能再用“距离衰减主控”理解。
6. 距离只能控制搜索范围和置信度，不能直接决定密度强弱。
7. 决定虚拟井密度变化的主逻辑应该是：
   - 同一源井对应点
   - 井周异常带连续性
   - 相干体 / 蚂蚁体 / 曲率 / 反演 / 振幅等属性响应变化

### Step 5. 单源井虚拟测井构造

目标：

1. 以单口真实井裂缝预测结果为源。
2. 向这口井周边地震道位置生成虚拟测井样本。
3. 为后续密度体学习扩充弱监督样本。

重要：

1. 当前不是跨井融合。
2. 当前是单源井局部外推。
3. 虚拟井定义是：
   - “如果这口井周边有井，井上裂缝会是什么样子”

历史旧目录：

`优化阶段二/虚拟测井构造`

旧目录原本 6 步逻辑是：

1. 候选虚拟井索引
2. 井周属性提取
3. 弱标签生成
4. 置信度计算
5. 训练样本汇总
6. DFN 井轨迹校正包

但旧实现关键问题是：

1. 复用源井中心道属性，而不是真实虚拟点属性
2. 用 `copy_and_distance_decay` 做主弱标签逻辑
3. 把距离衰减当成密度变化主控

这些都不能直接延续成正式新实现。

当前确认后的正确实现逻辑：

#### 5.1 候选虚拟井生成

1. 围绕单口真实井，在井周地震道网格上生成候选虚拟井。
2. 仍可保留 `5x5` 邻域骨架，但必须是“单井单独生成”。

#### 5.2 虚拟点属性提取

1. 对每个虚拟点，用它自己的 `X/Y/TIME` 去体数据中重新取值。
2. 不能复用源井中心道属性。
3. 主体属性包括：
   - 相干体
   - 蚂蚁体
   - 曲率
   - 反演
   - 振幅
4. 如有需要，还要计算虚拟点自己的 `3x3` 邻域统计。

#### 5.3 单井局部外推

1. 每个虚拟点只参考这口源井对应点。
2. 不能混入其他井的信息。
3. `Density` 的变化不由距离主导，而由属性异常带延续关系主导。

即：

- 如果虚拟点与源井对应点仍在同一条相干/蚂蚁异常带上
- 曲率和反演背景也相近
- 则可以继承接近的 `Density`
- 如果异常带断掉、偏掉、减弱，则下调或取消该点密度

#### 5.4 距离角色

距离不能再直接决定 `Density`，只能做：

1. 搜索范围限制
2. 置信度衰减
3. 平手条件下的弱修正

#### 5.5 单井虚拟测井结果

输出统一字段：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

辅助保留：

- `SourceWellName`
- `VirtualWellName`
- `PointConfidence`
- 必要属性列
