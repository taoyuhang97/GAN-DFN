# 第三步虚拟测井弱约束样本

本目录用于重构当前的“第二部分/第三步”流程：
不是直接生成最终 DFN，而是围绕真实测井裂缝预测结果，构造井周虚拟测井样本，用于后续三维连续裂缝密度体学习。

## 背景

第一部分已经得到真实测井轨迹上的统一结果，格式为：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

其中同时包含两层信息：

1. 连续裂缝密度曲线
2. 从密度曲线细化出的裂缝点位

现在这一步的目标，是把这些真实测井结果外推到井周地震道位置，形成“虚拟测井样本”。

## 新虚拟测井的定义

这里的“虚拟测井”不是实际井，也不是最终 DFN 单元格。

它的定义是：

- 建在真实井周边地震道上的一条虚拟轨迹
- 轨迹上的每个采样点仍然使用与真实测井一致的字段
- 它是井点约束向周边空间扩展后的弱监督样本

因此，虚拟测井的角色是：

**样本扩充层，不是最终成果层。**

## 目标输出

无论是真实测井还是虚拟测井，最终都统一为同一种表结构：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

可选附加字段：

- `SourceWellName`
- `VirtualWellName`
- `DistanceToSource`
- `PointConfidence`
- `WellConfidence`
- `COHERENCE`
- `ANT_TRACK`
- `CURVATURE_MAX`

## 整体流程

### 步骤1 候选虚拟井索引

围绕每口真实井，在其对应地震道附近构造 `5x5` 邻域虚拟井位置。

产出：

- `virtual_well_index.csv`

核心字段：

- `SourceWellName`
- `VirtualWellName`
- `SourceX`
- `SourceY`
- `VirtualX`
- `VirtualY`
- `DistanceToSource`

### 步骤2 井周属性提取

针对步骤1生成的每条虚拟井轨迹，补齐井周属性与主地震属性。

当前首版先复用真实井已有结果中的中心道属性；
后续应升级为按虚拟井 `X/Y/TIME` 真正读取邻近地震道上的属性值。

产出：

- `virtual_well_attributes.csv`

### 步骤3 弱标签生成

基于真实测井预测结果，将裂缝密度外推到虚拟井。

当前首版策略：

- 以真实井 `Density` 为源
- 结合平面距离做衰减
- 形成 `FractureDensityWeak`

后续可继续叠加：

- 相干体相似性
- 蚂蚁体相似性
- 曲率一致性
- 同层约束

产出：

- `virtual_well_density_weaklabel.csv`

### 步骤4 置信度计算

给每个虚拟点和每条虚拟井附加置信度。

当前首版仅基于距离衰减；
后续应加入属性相似性、断层阻隔、层位连续性等因素。

产出：

- `virtual_well_confidence.csv`

### 步骤5 训练样本汇总

将步骤2到步骤4的结果汇总成后续模型可直接使用的统一格式。

主输出字段：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

同时保留：

- `SourceWellName`
- `VirtualWellName`
- `PointConfidence`
- `WellConfidence`
- 若干井周属性列

产出：

- `virtual_well_training_samples.csv`
- `virtual_well_training_summary.csv`

## 这一步完成后能做什么

完成本目录流程后，将得到：

1. 真实测井轨迹结果
2. 井周虚拟测井轨迹结果
3. 井轨迹 DFN 校正控制结果

两者结构一致，可以直接合并，用于后续：

- 学习三维连续裂缝密度体
- 再基于三维密度体细化裂缝几何参数
- 最后用井上真实裂缝点位做校正

## 最终需要交付的三样东西

### 1. 真实测井上的连续裂缝密度曲线和裂缝点位

这是第一部分已经生成的结果。

用途：

- 作为后续学习连续裂缝密度体的高可信井点样本
- 也是后面所有外推与校正的真实基准

统一字段：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

### 2. 外推后的虚拟测井连续裂缝密度曲线和裂缝点位

这是本目录当前要重点构建的结果。

用途：

- 将真实井约束扩展到井周地震道位置
- 扩充后续三维连续裂缝密度体学习样本

统一字段：

- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`

### 3. 基于井点的 DFN 井轨迹校正控制包

这不是新的三维体，也不是新的虚拟井样本。

它的作用是：

- 当后续已经根据密度体细化出 DFN 裂缝片之后
- 再把这些 DFN 在井轨迹上的裂缝分布，向真实/预测的井上裂缝点位靠拢
- 保证最终展示给甲方时，井轨迹穿过 DFN 后看到的裂缝位置与井点控制尽量一致

可以把它理解为：

**“井轨迹上的最终校正标准答案/控制线”**

当前建议字段：

- `WellName`
- `X`
- `Y`
- `TIME`
- `Density`
- `HasFracture`
- `PredAzimuth`
- `PredDip`
- `ControlPriority`
- `ControlSource`

其中前五列仍然是最核心、必须统一保留的字段。

## 当前版本定位

当前代码是第一版工程骨架，优先解决三件事：

1. 统一目录和输入输出
2. 明确“虚拟测井 = 井周弱监督样本”
3. 先把真实井结果外推为结构化样本包

它还不是最终的高保真外推版本，但已经是后续继续加属性相似性和空间约束的稳定底座。

## 一键运行入口

可直接点击运行：

- `run_stage3_virtual_well_workflow_click.py`
- `一键运行_井周虚拟测井样本构建.py`

其中步骤5会自动输出统一格式的训练样本总表，便于直接接到后续三维连续裂缝密度体学习流程。
