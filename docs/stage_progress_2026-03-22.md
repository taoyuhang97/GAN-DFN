## 2. 项目背景与当前目标

当前项目的总体目标是围绕“优化阶段一”完成裂缝识别与点位细化，整体可分为三步：

1. 用“地震数据 + 常规测井”预测虚拟成像测井属性；
2. 用“地震数据 + 成像测井属性”预测裂缝发育段；
3. 在裂缝发育段基础上进一步细化出裂缝发育点位，为后续 DFN 构造提供输入。

当前真正的工作重心已经转到第 3 步，即：

- 不再单独追求第一阶段的 `accuracy`；
- 重点把“裂缝发育段”稳定地转换为“裂缝发育点位”；
- 评价重点转为“条数是否合理 + 点位距离是否合理”。

## 3. 当前总体流程

### 3.1 第一阶段：裂缝发育段预测

主脚本：

- `模型训练/优化阶段一/裂缝存在性分析/LSTM/imaging_well_to_fracture_cnn_lstm_test_1.py`

当前逻辑：

- 输入：地震属性 + 常规测井属性；
- 输出：逐深度点的裂缝发育概率 `PRED_PROB` 与标签 `PRED_LABEL`；
- 训练/验证方式：按井留一验证，不做井内随机切分；
- 训练井选择：按井间距离优先选择相近井，不是固定使用所有其他井。

当前代表实验：

- 目录：`E:\项目\石油项目\断缝储\原始数据\wx数据\砂砾岩\优化阶段一\研究内容一\裂缝存在性预测\LSTM\单井验证\成像测井裂缝预测\cnn+lstm\exp40_missing_drop_ac_gr_3x3_seq5_AC_GR`

| 车662 | 车660-1, 车660-2 |

其中当前保存下来的代表配置为：

- `DIST_THRESHOLD = 0.35`

### 3.2 第二阶段：裂缝点位细化

主脚本：

- `模型训练/优化阶段一/裂缝位置分析/基于密度的裂缝点位分析/raw_point_guided_segment_refine.py`

当前核心思路不是“直接逐点密度回归恢复真实裂缝形态”，而是：

1. 使用第一阶段输出的裂缝发育段；
2. 对每个预测段构建段级特征；
3. 预测或标定该段应生成多少个裂缝点；
4. 再按照段内概率形状把点位离散到深度轴上。

当前第二阶段训练/验证方式：

- 对某一口井做验证时：
  - 测试集 = 该井全部预测段样本；
  - 训练集 = 其余 3 口井全部段级样本；
- 不做井内随机切分；
- 当前已新增“训练井距离加权”开关，但默认仍可关闭。

### 3.3 实际应用时的部署逻辑

部署脚本：

- `模型训练/优化阶段一/裂缝位置分析/基于密度的裂缝点位分析/nearest_imaging_well_predict_then_refine.py`

实际预测一口常规测井时，当前拟采用：

1. 先计算该井与 4 口成像井之间的属性距离；
2. 选择最近的一口成像井；
3. 读取该井对应的第一阶段模型；
4. 再读取该井对应的第二阶段点位细化模型；
5. 按“先选模、再预测”的方式完成两阶段串联。

## 4. 当前采用的第二阶段方案

当前已经形成的主方案如下：

### 4.1 基础输入

- 第一阶段输出的 `PRED_LABEL`
- 第一阶段输出的 `PRED_PROB`
- 原始裂缝点标注
- 原始裂缝发育段标签

### 4.2 主要处理环节

1. 以第一阶段 `PRED_LABEL` 作为裂缝段基础门控；
2. 引入边界补偿 `prob_shoulder`，用相邻高概率点适度扩展预测段边界；
3. 针对每个预测段提取长度、概率均值、概率峰值、概率质量等段级特征；
4. 采用 Tweedie 回归 + 规则量纲回退的方式预测段内裂缝条数；
5. 对部分明显弱置信度段做选择性后处理下调；
6. 将段级点数离散成具体裂缝点位。

### 4.3 已实现的关键增强

- 边界补偿：`prob_shoulder`
- 段级总量标定
- 选择性后处理下调
- 新增指标：
  - `count_error_pct`
  - `overall_count_error_pct`
- 新增训练井距离加权开关：
  - `--train-distance-weight-mode`
  - `--train-distance-csv`
  - `--train-distance-weight-power`
  - `--train-distance-weight-min`
  - `--train-distance-weight-max`

## 5. 当前评价标准

当前第二阶段的目标更接近以下标准：

- 以第一阶段预测出的裂缝发育段为约束；
- 在该约束内尽量恢复与原始离散裂缝记录一致的条数；
- 同时尽量减小预测点位与真实点位的深度距离误差。

也就是说，当前更偏向：

- “预测得到的裂缝条数与真实条数尽量一致，且距离偏差尽量小”

而不是：

- “宁可只预测很少的点，只保留最强烈、最靠近真实点的少数点”

当前重点指标包括：

- `GT点数`
- `Pred点数`
- `点数差`
- `count_error_pct`
- `pred->gt_mean / p90`
- `gt->pred_mean / p90`
- `SegMAE`

### 6.3 距离加权强弱对比

已测试：

- `0.8 ~ 1.2`
- `0.7 ~ 1.3`
- `0.6 ~ 1.4`

结果基本一致，说明：

- 当前 4 口井之间的权重差异还不够大；
- 仅调整 `min/max clip` 对最终结果影响较小；
- 如果继续沿这个方向优化，更值得优先测试的是 `power`，而不是继续微调裁剪范围。

## 7. 当前问题判断

按井分析，当前主要瓶颈如下：

- `车660-1`
  - 仍然存在明显欠预测；
  - 当前距离加权后有改善，但仍未解决。
- `车660-2`
  - 已能较好控制条数；
  - 继续优化时要注意不要因整体下调而压掉有效真裂缝段。
- `车662`
  - 整体不稳定；
  - 数据量偏少，对模型波动较敏感。
- `车663`
  - 主要问题仍然来自第一阶段段覆盖不足；
  - 许多真实裂缝点位于预测段之外，第二阶段无法凭空恢复。

因此当前应当明确：

- 第二阶段已经不是唯一瓶颈；
- 尤其 `车663` 的上限，明显受第一阶段裂缝段覆盖质量制约。

## 8. 当前阶段性结论

1. 单纯逐点密度回归并没有学出稳定的段内形态，当前不宜作为主路线。
2. “预测段 -> 段级总量标定 -> 段内概率分配”的路线目前更稳定。
3. 边界补偿和选择性后处理是当前有效的关键增强项。
4. 距离加权目前是小幅正向收益，建议保留为开关，不建议立即强制作为默认方案。
5. 第二阶段后续优化空间仍在，但 `车663` 这类井的上限已开始受到第一阶段段覆盖率约束。

## 9. 下一步建议

建议优先顺序如下：

1. 继续测试距离加权的 `power`，例如 `0.5` 与 `2.0`；
2. 重点分析 `车660-1` 欠预测来源，优先补条数不足问题；
3. 对 `车663` 明确区分：
   - 是第二阶段条数分配问题；
   - 还是第一阶段预测段漏检问题；
4. 在最终部署前，将“最近成像井选模 + 两阶段串联预测”的流程再做一次端到端固化。
