# 第一轮优化阶段代码补充说明（2026-05-06）

## 1. 文档目的

本文档用于说明 `2026-05-06` 这次追加上传到 `upload/first-round-improvement-20260420` 分支的代码范围、改动目的和明确排除项。

本次说明只覆盖相对于 `2026-05-04` 之后新增的代码补充，不重复前一版主线流程整理。

## 2. 本次上传范围

本次实际上传了 7 个正式代码文件，分为 3 组。

### 2.1 DFN 实例互转保真修正

位于：

- `研究内容三/优化阶段一/DFN实例表达互转实验/`

对应文件：

- `dfn_patches_to_instance_label.py`
- `instance_label_to_dfn_patches.py`
- `instance_roundtrip_common.py`
- `run_dfn_instance_roundtrip_experiment.py`

本组改动重点包括：

- 将实例标签中的来源类型、层段归属和单元层段键映射写入元数据。
- 解码时优先根据编码阶段保留的映射恢复原始层段信息，而不是只依赖中心时间重新归层。
- 增加 `PatchArea` 字段在实例互转中的保留与回写，减少 round-trip 后面积信息丢失。
- 统一法向量与面内方向向量的规范化和符号约束，减少同一裂缝片在编码和解码前后的方向漂移。
- 将实例互转默认 `slots_per_voxel` 从 4 提升到 16，使互转实验与当前 G-DFN 主流程的多槽位设置保持一致。

### 2.2 G-DFN 稀疏样本打包与读取兼容补充

位于：

- `研究内容三/优化阶段一/GAN训练准备/训练样本打包/`
- `研究内容三/优化阶段一/G_DFN监督基线/`

对应文件：

- `build_sparse_instance_gan_dataset.py`
- `baseline_common.py`

本组改动重点包括：

- 调整窗口内实例排序规则，优先保留 `real -> virtual -> seismic_gradient_fill` 的来源优先级。
- 排序时不再只依赖方位角，而是更多使用中心偏移、法向量、面内方向和裂缝尺寸，减少同体素内实例顺序漂移。
- 将 `count_volume` 的存储类型从 `uint8` 提升到 `uint16`，避免高密度体素的数量截断。
- 训练读取阶段补充读取 `instance_source` 和 `instance_patch_index` 字段，保证稀疏包字段兼容。
- 取消 `count_target` 按 `slots_per_voxel` 的上限裁剪，避免训练标签在高密度体素处被过早压平。

### 2.3 DFN 体素双轮互转统计脚本补充

位于：

- `研究内容三/优化阶段一/DFN体素互转实验/`

对应文件：

- `run_two_pass_roundtrip_statistics.py`

本脚本的作用是：

- 筛选适合做互转统计的代表性单元。
- 对选定单元执行两轮 `DFN -> 体素 -> DFN` 转换。
- 输出两轮互转前后的数量、几何和体素重叠统计结果。
- 为“第一轮会丢失多少信息、第二轮是否趋于稳定”提供统一统计入口。

## 3. 本次改动与当前 G-DFN 主流程的关系

这次补充不是新增一条独立生产主线，而是围绕当前第三部分已经在使用的“稀疏实例标签 + 参数场”表达做保真增强。

从主流程关系上看：

1. `build_sparse_instance_gan_dataset.py` 负责把单元 DFN 裂缝片编码成训练样本。
2. `baseline_common.py` 负责在训练阶段把稀疏标签还原成监督张量，并在推理阶段把网络输出重新组织成实例标签。
3. `instance_roundtrip_common.py` 负责实例标签和裂缝片之间的编码/解码基础逻辑。

因此，本次改动本质上是在强化：

- 训练样本编码的一致性。
- 推理解码后的层段归属稳定性。
- 裂缝片面积、来源类型和层段标识等辅助信息的保留能力。

这组改动更偏向“几何与标识保真修正”，不是直接针对层内裂缝数量校准的修改。

## 5. 本次上传结论

本次上传可以理解为对“第三部分实例表达链”的一次补强，主要价值有 3 点：

1. 提高 DFN 裂缝片在实例互转过程中的层段归属恢复能力。
2. 提高稀疏训练样本与推理解码之间的字段一致性和数量上限兼容性。
3. 补充双轮互转统计脚本，为后续汇报和表示方式评估提供统一的数据分析入口。

如果后续继续推进第三部分 G-DFN 结果优化，本次上传应作为“表示层保真修正”的基线版本使用。
