# 补充材料 `SGY` 头部说明（20260623）

本文档整理 `/data/shared/project-oil/wx数据/砂砾岩/补充材料-20260623` 下 6 个新增 `SGY` 文件的头部摘要，用于后续判断数据格式、物理意义和可用性。

当前结论先说明两点：

1. 这 6 个文件都可以被 `segyio` 正常读取；
2. 它们更像是规则网格化的地震/属性体，而不是井曲线文件。

## 2. 头部字段解读

### 2.1 `tracecount`

表示整份 `SGY` 文件包含的地震道数。这里 6 个文件基本都在 250 万到 299 万道之间，说明它们是大范围规则覆盖的体数据。

### 2.2 `nsamples` 与采样轴

表示每条地震道上的样点数，也就是每条道沿时间/深度方向的离散长度。

当前读到的采样轴范围有两类：

- `1100.0 - 3674/3676/3800` ms，配套 `bin interval = 2000 us`，即 2ms 采样；
- `1001.0 - 3637/3675/3676` ms，配套 `bin interval = 1000 us`，即 1ms 采样。

这说明不同属性体的时间采样并不完全一致，后续联合使用时需要先统一采样轴。

### 2.3 `bin format code`

6 个文件的 `bin format code` 都是 `1`，表示样点数据可以被 `segyio` 按标准 SEG-Y 浮点/振幅序列读取。

### 2.4 `trace0` 的缺失值

多个文件的前几个样点出现 `-9999999`，这是典型的缺失值填充，不应当当作真实物理值参与分析。

后续做属性对齐、插值或裂缝识别时，应先屏蔽这类值。

### 2.5 `TraceHeader` 字段

当前脚本读取到的关键头字段包括：

- `SourceX`
- `SourceY`
- `GroupX`
- `GroupY`
- `CDP_X`
- `CDP_Y`
- `INLINE_3D`
- `CROSSLINE_3D`
- `offset`

这批数据的一个特点是：`SourceX/SourceY` 有值，但 `CDP_X/CDP_Y/INLINE_3D/CROSSLINE_3D` 基本为 0，说明不能直接依赖道头自带的三维网格索引，后续更可能需要借助外部坐标表或已有井-道映射表来完成空间定位。

## 3. 物理意义与裂缝相关性

这 6 个文件里，真正和裂缝发育直接相关的，是属性体而不是“单纯振幅体”。它们分别承担不同角色：

- `最大曲率体` / `最大正曲率体`：反映构造弯曲和应变集中位置，常用于识别裂缝发育带、褶皱边缘和局部应力集中区；
- `相干体`：反映地震反射连续性，低相干通常意味着断裂、不连续或破碎带；
- `蚂蚁体`：常用于突出不连续边界和线性异常，适合辅助识别断裂/裂缝发育趋势；
- `裂缝反演数据`：更接近裂缝强度或裂缝发育概率的估计结果，可作为裂缝敏感性直接参考。

因此，后续从这些文件里提取裂缝相关信息时，通常不是“直接读出裂缝”，而是做三类工作：

1. 识别低相干、高蚂蚁体、高曲率的异常区；
2. 把这些异常区与井控裂缝密度结果对齐，建立相关性；
3. 作为第二步密度曲线和后续 DFN 生成的空间约束输入。

## 4. 当前使用建议

1. 先统一采样轴，再做多属性联合分析；
2. 所有 `-9999999` 先按缺失值处理；
3. 不要直接把属性值当裂缝真值，只把它们当裂缝敏感特征；
4. 若后面要与井数据拼接，优先按井周空间位置和层位对齐，不要只依赖 `TraceHeader` 中的 3D 索引字段。
