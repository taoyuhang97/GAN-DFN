## 2. 项目整体逻辑

### 2.1 总目标

项目总目标是构建矿区尺度的 DFN 模型。当前工作属于“优化阶段一”，总体策略是：

1. 先在井尺度上尽可能恢复裂缝位置、密度强度和方向信息
2. 再把这些井尺度结果迁移到虚拟测井和单元尺度
3. 最终为矿区尺度 DFN 提供可用的输入约束

### 2.2 统一后的三部分路线

#### 第一部分：基于测井的裂缝信息预测

目标是把已有成像测井井段中的裂缝知识迁移到更多常规测井或虚拟测井上，形成后续 DFN 所需的基础裂缝属性约束。

当前第一部分已经统一为两阶段主线：

1. 第一阶段：按地层预测裂缝发育段 / 裂缝存在概率
2. 第二阶段：在发育段内细化裂缝点位，并输出密度和倾向倾角相关结果

第一部分最终服务的不是“竞赛式单次指标”，而是后续 DFN 的输入约束。

#### 第二部分：虚拟测井构建与单元 DFN 生成

当前统一理解是：

1. 先在矿区内做单元划分
2. 对没有实测成像/常规测井覆盖的单元构建虚拟测井
3. 将第一部分的方法应用到虚拟测井，得到单元内裂缝分布约束
4. 把裂缝结果从井深域映射到单元空间
5. 补足单元 DFN 所需的几何参数、方向参数、密度 / 尺度参数和空间定位方式

#### 第三部分：矿区尺度 DFN 生成

当前统一理解是：

1. 以已有单元 DFN 和地震响应为训练样本
2. 学习“地震特征 -> DFN 表达”的映射
3. 补全全矿区其他单元 DFN
4. 再做跨单元拼接与边界协调，生成矿区尺度 DFN

## 4. 第一部分当前统一理解

### 4.1 第一部分的核心目标

第一部分当前不是单纯做“裂缝发育段预测”，而是整个项目三大步骤中的第一步：

`在测井尺度上尽可能恢复裂缝位置、密度强度和方向信息，为后续虚拟测井和单元 DFN 提供输入约束。`

### 4.2 当前第一部分已实现的主流程

当前流程已经统一为：

1. 对成像样本按地层做人工切分和标注
2. 第一阶段按地层训练裂缝存在性模型
3. 第二阶段按地层训练裂缝点位细化模型
4. 构建分地层专家模型库
5. 目标井部署时先按层位切分
6. 每个层内做专家井选择
7. 先跑第一阶段，再跑第二阶段
8. 最后把各层结果拼接成整井结果

### 4.3 当前专家模型选择逻辑

当前专家选择逻辑已经明确为：

1. 先做地层归属确定
2. 再在该地层内部选择专家模型

当前生产部署口径是：

- 如果目标井已经给定层位数据，就按给定层位切分
- 不再像早期 `车660-2` 测试那样把输入人为拆成多个未知区间再判层

### 4.4 当前第一部分已能输出什么

当前第一部分已经能输出：

- 分层裂缝发育段预测结果
- 分层裂缝点位预测结果
- 段级和点级的密度字段
- 段级和点级的倾向倾角结果
- 分层归属与模型选择解释信息

当前还不能直接输出：

- 可直接用于 DFN 的最终裂缝片长宽
- 完整裂缝 `XYZ` 几何面片参数
- 从井深域结果到单元内部裂缝片的最终映射结果

- 单点裂缝空间约束

- `PointDensityMassPerLengthAllocated`

- 段级裂缝范围约束

## 11. 当前仍需保留的风险意识

### 11.1 数据量仍然太少

当前监督样本很少，尤其目标矿区内真正落在核心范围的成像井更少，因此：

- 专家模型选择容易受单井差异影响
- 跨层泛化仍不稳
- 第二部分构建单元 DFN 时应更多采用“约束 + 规则 + 地质解释”混合方式

### 11.2 第一部分仍是后续上限约束

如果第一阶段漏检严重，第二阶段无法凭空恢复真实裂缝点位。

因此第二部分不要把第一部分输出当成“真值”，而应把它理解为：

- 有偏但有信息量的裂缝先验

### 11.3 当前还没有最终 DFN 几何表达

当前结果仍主要在井深域，不是最终 DFN 几何域。

第二部分必须补上：

- 井深到空间的映射
- 空间单元与测井 / 虚拟测井的关系
- 单元内部裂缝几何生成方式

### 11.4 密度和方向仍是中间约束

虽然当前已经有：

- 段级密度：`PredP10MassPerLength`
- 点级密度：`PointDensityMassPerLengthAllocated`
- 段级 / 点级倾向倾角结果
