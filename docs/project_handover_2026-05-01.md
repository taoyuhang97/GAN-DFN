## 2. 项目总目标与当前主线

### 2.1 项目总目标

本项目最终目标是生成整个矿区范围内的离散裂缝网络 DFN，而不是单纯完成某个 GAN 或监督模型的算法验证。整体思路是把成像测井、常规测井、地震解释与单元级/区域级 DFN 生成串成一条完整链路。

最终需要回答的不是“某个模型指标是否更高”，而是：

- 常规测井裂缝预测是否足够可信，能否作为矿区裂缝约束来源。
- 虚拟测井扩充是否足够可靠，能否把井间裂缝信息向区域传播。
- 最终生成的 DFN 在地质上是否“像”，能否用于矿区级解释与后续应用。

### 2.2 当前主线

当前阶段的主线重点有两条，但优先级并不完全相同：

1. 研究内容一主线  
   从成像测井裂缝样本出发，构造“按层位拆分训练得到的专家模型库”，再用于常规测井的两阶段裂缝预测，并为后续区域 DFN 提供约束。这条线目前已经进入“0.2ms 统一采样重构后重新建库”的阶段。

2. 研究内容三并行改造线  
   在已有单元 DFN、区域 DFN 合并与后处理基础上，继续做多尺度裂缝聚合、分层单元 DFN 构建以及区域断层后融合。

当前如果只看“最需要继续落地的主战场”，仍然是研究内容一，因为它直接决定后续虚拟测井与区域 DFN 的输入质量。

## 3. 整体流程地图：研究内容一、二、三如何串联

项目整体链路不是三个孤立子题，而是上下游关系：

1. 研究内容一  
   利用成像测井样本，构造分层专家模型库；再把专家模型应用到常规测井，得到井级裂缝发育段、裂缝点位及产状信息。

2. 研究内容二  
   把井级裂缝结果与地震单元、虚拟测井、单元裂缝归属结合起来，在井间区域扩充裂缝约束，并生成单元级 DFN 输入包。

3. 研究内容三  
   在单元级输入包基础上生成单元 DFN，做批量合并、地球物理后处理、裂缝片差异放大与区域断层后融合，最终形成区域 DFN。

简化后的总链路可以理解为：

`成像测井样本 -> 分层专家模型库 -> 常规测井两阶段裂缝预测 -> 井间虚拟测井与单元裂缝归属 -> 单元 DFN -> 区域 DFN 合并与后处理 -> 区域断层后融合`

当前中期汇报不追求单一总分，采用三级评估体系：

1. 一级：证明裂缝识别准  
   主讲 Recall、Precision、F1、IoU，用地质语言解释为命中率、可信度、综合符合度、段长重合度。Accuracy、AUC 放附录。

2. 二级：证明虚拟测井扩充可靠  
   主讲虚拟井与实测井的均值、离散程度、偏度、层段达标率。当前已确认 AC 整体优于 GR。

3. 三级：证明最终 DFN 在地质上“像”  
   不只看裂缝数，而是看发育段命中率、方位角偏差、倾角偏差、数量级偏差。

### 6.3.2 当前阶段一结果问题

根据已记录的问题文档，当前 0.2ms 第一阶段版本已经跑通，但质量不能作为正式定版。已确认的核心问题不是“脚本没跑起来”，而是“跑起来后预测发育段位置与真实发育段重合较差”。

### 6.3.3 当前阶段二结果问题

- 部分井层虽然有覆盖段，但最终点数仍被压到 0，说明阶段二当前策略本身也偏保守。

### 8.3.2 当前断层融合逻辑

简化理解如下：

1. 读取已有区域 DFN。
2. 从断层 patches 总目录里按区域范围找出相关断层面片。
3. 构造区域级断层面板。
4. 根据断层距离对原始 DFN 中靠近断层的裂缝做去除或缩小处理。
5. 生成断层本体及其次生裂缝。
6. 把断层影响结果嵌入原始区域 DFN，输出融合结果。

### 8.3.3 当前状态

这条链路已经具备“一条命令直接生成融合后 DFN”的能力，代码也已实际调试过。

但视觉和几何效果仍未达到最终满意状态，当前已知问题包括：

- 断层片重叠程度偏高。
- 平行于断层与垂直于断层的次生裂缝不够明显。
- 使用 `PatchArea` 着色时颜色差异不明显，尺寸层级对比不足。
- 有时看起来断层连续性过好，看不出面片拆分。
- 用户希望后续的断层面拆分更接近原始断层 patch 的几何形态，而不是简单矩形化。
- 用户还要求：不要在单元与单元之间人为拉开间隙，而应更侧重打断不同断层面片之间的连续感。

因此，这条线当前状态应理解为：

- 代码主框架已形成。
- 正式目录与单命令入口已存在。
- 但视觉表达与地质合理性仍在迭代，不应认为已经完全定型。
