# 当前任务说明

## 1. 文档目的

本文档用于收敛当前对项目任务的最新统一理解，作为后续新对话中继续实现的直接依据。

本文档重点说明：

1. 当前任务到底是什么；
2. 当前任务不是什么；
3. 当前默认采用的数据口径和流程口径；
4. 后续实现应按什么主线推进；
5. 当前哪些内容可以先做，哪些内容应暂缓。

本文档不展开到底层算法实现细节，也不替代后续代码设计文档。

## 2. 当前任务的正式定义

当前任务不是直接做整个矿区的最终结果，也不是只做单井附近的小玩具 demo。

当前任务应定义为：

**在矿区内部选择一个局部验证区域，先跑通“局部矿区尺度密度体 -> 局部初始 DFN -> 井控矫正”这条完整主线，用于验证后续全矿区方案是否可行。**

换句话说：

- 方法链条是按未来全矿区主线设计的；
- 但当前实现范围先限制在矿区内部一个局部子区；
- 目的是先验证路径是否成立，而不是先产出全矿区正式成果。

## 3. 当前任务不是什么

为避免后续实现方向再次偏移，明确以下几点。

### 3.1 不是单井小范围闭环 demo

当前任务不是：

- 只围绕一口井做 `5x5` 或 `9x9` 的近井样本展示；
- 只验证井周局部密度插值是否成立；
- 只做一个井旁可视化样例。

井仍然重要，但当前验证目标已经上升到“局部区域尺度的方法路径验证”。

### 3.2 不是直接做全矿区正式结果

当前任务也不是：

- 直接对整个矿区输出最终三维裂缝密度体；
- 直接生成整个矿区最终 DFN；
- 直接进入最终汇报结果阶段。

原因是当前矿区范围过大，直接全区推进风险高、调试成本高、返工代价高，因此先做局部区域验证。

### 3.3 不是当前就做完整几何细化定型

当前任务也不是马上把：

- 裂缝倾向；
- 裂缝倾角；
- 裂缝片尺度；
- 裂缝片几何生成规则；
- 最终 DFN 细化策略

全部一次性做死。

当前更重要的是先把“密度体 -> 初始 DFN -> 井控矫正”这条大链跑通。

## 4. 当前主线的统一口径

当前统一采用的后续主线为：

`局部验证区域属性体 + 井上裂缝监督 -> 局部三维裂缝密度体 -> 局部初始 DFN -> 井控矫正`

这条主线分成三层理解。

### 4.1 第一层：监督来源

监督核心来自井上的裂缝信息，包括：

- 井上的裂缝密度；
- 井上的具体裂缝点位；
- 与井轨迹对应的属性体信息。

### 4.2 第二层：中间控制对象

后续流程的核心中间对象不是直接的裂缝片，而是：

- **三维裂缝密度体**

也就是说，先回答：

- 哪些区域裂缝更发育；
- 哪些区域裂缝较弱；
- 局部空间发育格局大致怎样。

### 4.3 第三层：最终几何结果

在密度体基础上再进一步生成：

- 局部初始 DFN；
- 然后再利用井上裂缝点位进行井控矫正；
- 让最终局部 DFN 与井上裂缝预测结果尽量一致。

## 5. 当前默认前提

当前前提是：前三步不在本轮里重做，而是把它们视为已完成或由别人负责推进。

### 5.1 前三步状态假定

当前统一假定：

1. 数据基准统一已经完成；
2. 真实井裂缝预测已经完成；
3. 虚拟测井构造模块由其他人继续推进。

### 5.2 第三步输出的临时统一表达

由于第三步真实模块还未完全交付，当前先把第三步输出统一抽象为一张**井轨迹点级样本表**。

当前预计这张表至少包含以下字段：

- `X`
- `Y`
- `TIME`
- `裂缝密度`
- `是否是具体裂缝点`
- `蚂蚁体/相干体/地震振幅等体数据时窗`

它与第一轮优化阶段已有的常规测井裂缝结果结构比较接近，因此当前先按这一口径推进后续流程。

### 5.3 这张临时样本表的定位

这张表当前只能理解为：

- **后续流程的临时统一输入接口**

不能过度理解为：

- 已完全定型的第三步正式输出；
- 已经足够代表完整空间样本体系；
- 已经足够支撑最终全矿区定量结论。

后续真实第三步结果出来后，字段和语义仍可能补充或修订。

## 6. 当前任务的阶段划分

后续实现建议先按 6 个阶段组织。

### 阶段一：统一井轨迹点级样本表

目标：

- 把第三步临时输出统一成标准样本表；
- 固定字段、缺失值规则、样本来源标记；
- 形成后续流程统一输入接口。

作用：

- 把井上裂缝信息和空间属性体信息接到同一条链上。

### 阶段二：点级监督样本整理与基础统计

目标：

- 围绕样本表整理监督对象；
- 统计裂缝点/非裂缝点、裂缝密度、属性可用率、不同样本来源占比等。

作用：

- 明确当前监督信息到底够不够支撑后续密度学习。

### 阶段三：局部验证区域的空间网格/体素框架构建

目标：

- 在选定的局部验证区内建立统一空间表达；
- 将井轨迹点样本和体数据映射到网格或体素上。

作用：

- 为三维裂缝密度体预测准备统一空间底座。

### 阶段四：局部三维裂缝密度体学习输入集构建

目标：

- 构造适用于局部区域密度学习的训练/验证输入；
- 完成点级监督向空间输入格式的转换。

作用：

- 形成正式进入密度体预测的可用输入集。

### 阶段五：局部三维裂缝密度体生成

目标：

- 在局部验证区域内生成三维裂缝密度体；
- 形成可视化和回验用的空间结果。

作用：

- 验证“井上监督 -> 空间裂缝密度体”这条路径是否成立。

### 阶段六：局部初始 DFN 与井控矫正

目标：

- 基于局部密度体生成局部初始 DFN；
- 利用井上的裂缝点位和井上预测结果进行局部井控矫正。

作用：

- 验证“密度体 -> 初始 DFN -> 井控矫正”这条完整路径是否成立。

## 7. 当前阶段真正要验证的内容

这次局部区域验证，真正要回答的是下面三个问题。

### 7.1 能不能从稀疏井控走到空间密度体

也就是：

- 利用当前井上裂缝密度监督和属性体输入；
- 能否在局部区域内形成稳定、可解释的三维裂缝密度体。

### 7.2 密度体能不能支撑初始 DFN 生成

也就是：

- 裂缝密度体是否足够作为后续几何细化和初始 DFN 生成的主控中间层。

### 7.3 DFN 能不能通过井控矫正与井上结果对齐

也就是：

- 局部初始 DFN 经过井控矫正后；
- 是否能与井上的裂缝点位和井上预测结果基本对应。

## 8. 当前 demo 的正确理解

当前这里所说的 demo，必须按下面的方式理解：

- 它是**局部区域的矿区尺度方法路径验证**；
- 不是单井附近的小样例；
- 也不是全矿区正式成果。

因此：

- 空间范围上，它是矿区内部的一个局部子区；
- 方法链条上，它仍然对应完整主线；
- 目标是验证路径，不是立即交付最终矿区结果。

## 9. 局部验证区域的当前默认口径

当前收敛后的建议是：

- 以 `车页1导眼` 所在位置为中心；
- 在矿区内部选择一个围绕该井的局部验证区；
- 平面上建议先从一个能承载局部密度体和局部 DFN 的窗口开始；
- 垂向上严格限制在目标层段 `T4-T7`。

需要特别注意：

- 这个区域不应再理解成单纯的 `5x5` 或 `9x9` 井周邻域展示窗口；
- 它应是一个足以承载“局部区域密度体 -> 局部初始 DFN -> 局部井控矫正”完整路径的局部子区。

具体区域大小可以在后续实现时再结合数据条件继续细化，但当前总口径已经确定：

- **区域中心贴井；**
- **范围属于矿区局部子区；**
- **垂向只看 `T4-T7`。**

## 10. 当前可以先做的内容

在第三步正式结果未完全交付前，当前可以先推进以下内容：

- 统一点级样本表接口；
- 字段说明、缺失值规则、样本来源规则；
- 点级监督样本整理；
- 局部区域网格/体素底座搭建；
- 局部三维裂缝密度体输入集设计；
- 局部三维裂缝密度体预测框架；
- 井点回验框架；
- 初始 DFN 和井控矫正的接口设计。

这些内容的共同特点是：

- 不依赖第三步最终实现完全定稿；
- 能直接为后续大链做准备；
- 返工风险相对可控。

## 11. 当前应暂缓的内容

当前应暂缓以下内容：

- 直接做全矿区正式结果；
- 直接定最终全矿区三维裂缝密度体；
- 直接定最终裂缝倾向、倾角细化策略；
- 直接定最终裂缝片生成规则；
- 直接定最终全矿区 DFN；
- 直接把当前局部验证结果当成方法最终定型依据。

原因是当前第三步仍是临时统一接口，过早推进这些内容，后续返工代价会很高。

## 12. 当前最容易返工的部分

为了后续控制风险，需要明确当前最容易返工的地方。

### 12.1 第四步关系整理

一旦第三步正式输出字段或语义变化，基于临时样本表做的关系整理最容易先重算。

### 12.2 样本表到空间表达的接口

如果当前临时样本表和后续真实第三步输出不一致，点级样本到网格/体素的映射接口会整体返工。

### 12.3 任何过早的几何细化

如果在密度体尚未稳定之前就提前做倾向、倾角、裂缝片细化，后续返工概率最高。

## 13. 当前建议的实现终点

在当前轮次中，最建议先推进并稳定到的终点是：

**局部验证区域的三维裂缝密度体生成 + 局部初始 DFN + 井控矫正路径验证**

如果需要再细分优先级，则优先顺序为：

1. 点级样本表统一；
2. 局部三维裂缝密度体；
3. 井点回验；
4. 局部初始 DFN；
5. 井控矫正。

## 14. 一句话总结

当前任务的最新统一定义是：

**先把第三步临时统一成井轨迹点级样本表，在矿区内部选一个局部验证区域，先跑通“局部三维裂缝密度体 -> 局部初始 DFN -> 井控矫正”这条完整主线，用于验证后续全矿区方案是否成立。**
