# 地震解释一致性体实施规划

日期：2026-07-09

适用范围：`优化阶段二/正式主线` 车页1导眼 `candidate_cheye1` demo 区。

## 1. 目标

当前 `lowcoh_steep` 版本已经提高了 DFN 与相干体低值垂向异常的匹配程度，但没有显式使用蚂蚁体和曲率体，因此 DFN 与现有地震解释体仍不够一致。下一阶段新增 `seismic_prior_v1` 路径，目标是构造一个统一的地震解释一致性体 `SeismicPrior`，用它修正三维裂缝密度体，再驱动 Step7B-Step9 生成 DFN 和剖面图。

核心原则：

- 不覆盖 `candidate_cheye1`、`lowcoh_add`、`lowcoh_steep` 任何既有结果。
- 第一版只改 Step6B 后处理和配置链路，Step7B/Step7C/Step8 主逻辑先不改。
- 优先让 DFN 同时贴近 `AntTrack` 高值、`Coherence` 低值垂向异常和 `CurvatureMax` 高值。
- 不把相干体横向低值条带直接当作裂缝发育带。
- 所有结果必须输出独立 QC JSON，支持和 `original_fused`、`lowcoh_steep` 对比。

```json
  "trace_mapping_npz": "...candidate_cheye1_3d_trace_mapping.npz",
  "volume_paths": {
    "Coherence": "...车西-相干体T4-T7.sgy",
    "AntTrack": "...车西-蚂蚁体T4-T7.sgy",

  },

  "output_density_sgy_name": "candidate_cheye1_3d_predicted_density_seismic_prior_v1.sgy",
  "output_prior_sgy_name": "candidate_cheye1_3d_seismic_prior_v1.sgy",
  "output_trace_mapping_name": "candidate_cheye1_3d_trace_mapping.npz",
  "output_summary_name": "candidate_cheye1_3d_density_seismic_prior_v1_summary.json"
}
```

### 4.3 属性体读取策略

沿用 Step6B 当前 SGY 处理策略：

- 以 `input_density_sgy` 的 trace 和 time samples 为目标网格。
- 使用 `trace_mapping_npz` 中的 `source_trace_idx` 从原始属性体读取对应 trace。
- 如果属性体 sample axis 与密度体不一致，使用一维插值对齐到密度体 samples。
- 过滤无效值：非有限值、`<-1e6` 或 `>1e6` 视为无效。
- 输出 SGY 继承原密度体 trace header。

### 4.4 单属性评分

#### 4.4.1 AntTrackHighScore

口径：`AntTrack` 高值表示裂缝发育响应强。

计算：

```text
AntTrackHighScore = clip((AntTrack - q20) / (q95 - q20), 0, 1)
```

参数：

```json
"anttrack_score": {
  "valid_min": -1000000.0,
  "valid_max": 1000000.0,
  "low_quantile": 0.20,
  "high_quantile": 0.95,
  "power": 1.0
}
```

#### 4.4.2 LowCoherenceScore

口径：相干体低值表示不连续，但横向层位条带不能直接作为裂缝。

基础低相干分数：

```text
LowCoherenceScore = clip((q95 - Coherence) / (q95 - q05), 0, 1)
```

参数：

```json
"coherence_score": {
  "valid_min": 0.0,
  "low_quantile": 0.05,
  "high_quantile": 0.95,
  "power": 1.2
}
```

#### 4.4.3 SteepLowCoherenceScore

复用 `lowcoh_steep` 的三维连通体形态思想：

```text
SteepLowCoherenceScore = LowCoherenceScore * component_vertical_multiplier
```

连通体判定：

- `LowCoherenceScore >= component_score_threshold` 提取低相干异常体。
- 三维 26 邻域连通。
- 横向范围大、时间厚度小的连通体视作层位条带，强惩罚。
- 时间方向延伸明显的连通体视作垂向异常，保留或增强。

建议参数：

```json
"steep_anomaly": {
  "enabled": true,
  "component_score_threshold": 0.55,
  "use_26_connectivity": true,
  "min_vertical_time_samples": 6,
  "strong_vertical_time_samples": 18,
  "horizontal_max_time_samples": 5,
  "horizontal_min_xy_cells": 60,
  "horizontal_sheet_penalty": 0.90,
  "min_component_multiplier": 0.08,
  "max_component_multiplier": 1.0
}
```

#### 4.4.4 CurvatureMaxHighScore

口径：`CurvatureMax` 高值表示构造变形强。

第一版使用高值归一化：

```text
CurvatureMaxHighScore = clip((CurvatureMax - q50) / (q98 - q50), 0, 1)
```

原因：曲率体噪声通常比 AntTrack 更强，用 q50-q98 可减少低幅背景参与。

建议参数：

```json
"curvature_score": {
  "low_quantile": 0.50,
  "high_quantile": 0.98,
  "power": 1.0,
  "smooth_xy_cells": 0,
  "smooth_time_samples": 0
}
```

初版不平滑；如果 QC 发现曲率噪声过强，再加轻微平滑。

### 4.5 SeismicPrior 合成

初版使用加权加法：

```text
SeismicPrior =
  0.50 * AntTrackHighScore
+ 0.35 * SteepLowCoherenceScore
+ 0.15 * CurvatureMaxHighScore
```

再裁剪到 `[0, 1]`。

配置：

```json
"prior_weights": {
  "anttrack_high": 0.50,
  "steep_low_coherence": 0.35,
  "curvature_max_high": 0.15
}
```

不使用乘法作为初版主逻辑，原因是乘法会要求多个属性同时高，可能导致先验体过稀疏，DFN 难以连续。

### 4.6 密度体修正

输出密度：

```text
DensityOut = BaseDensity * (1 + gain * SeismicPrior)
           + additive_alpha * DensityScale * SeismicPrior^power
```

建议参数：

```json
"density_update": {
  "gain": 1.2,
  "additive_alpha": 0.30,
  "additive_density_scale_quantile": 0.95,
  "additive_power": 1.3,
  "density_cap": 10.0,
  "preserve_zero_density": true
}
```

关于 `preserve_zero_density`：

- 若为 `true`，原始密度为 0 且先验不强的位置保持 0。
- 允许强先验区通过加性项补充密度，解决低密度但地震解释强的位置无法生成裂缝的问题。


### 4.8 Step6B QC

summary JSON 必须包含：

```text
BaseDensity stats
AntTrack stats and quantile bounds
AntTrackHighScore stats
Coherence stats and quantile bounds
LowCoherenceScore stats
SteepLowCoherenceScore stats
CurvatureMax stats and quantile bounds
CurvatureMaxHighScore stats
SeismicPrior stats
DensityOut stats
DensityDelta stats
```

必须包含对齐指标：

```text
DensityOut top 1% 落在 AntTrack >= q80/q90 的比例
DensityOut top 1% 落在 Coherence <= q20 的比例
DensityOut top 1% 落在 CurvatureMax >= q80/q90 的比例
DensityOut top 1% 落在 SeismicPrior >= q80/q90 的比例
```

复查标准：

- `DensityOut` 高值区应比原始 `BaseDensity` 更贴近 `AntTrack >= q80`。
- `DensityOut` 高值区不能明显远离 `Coherence <= q20`。
- `SeismicPrior` 中位数不能过高，避免全区都被增强。
- `DensityOut` 不能大量达到 `density_cap=10.0`，否则说明增强过强。

### 7.2 初版策略

第一版不改 Step8 代码。原因：先判断 Step6B 源头修正是否有效，避免 Step8 同时变化导致无法定位问题。

保持现有逻辑：

- Step3 成像测井真实裂缝：硬约束，保留真实倾向倾角。
- Step4 常规测井预测裂缝：软井控，继承附近 DFN 模板方向。
- 裂缝片大小随井点裂缝密度变化。
- 井控片中心允许小范围偏移。

### 7.3 后续可选增强

若 Step8 仍破坏地震一致性，再实现软井控筛选：

```text
WellSeismicSupport = max(AntTrackHighScore, SteepLowCoherenceScore, CurvatureMaxHighScore)
```

规则：

```text
成像测井真实裂缝：不筛选，直接保留
常规测井预测裂缝且 WellSeismicSupport 高：正常新增或调整
常规测井预测裂缝且 WellSeismicSupport 中：缩小裂缝片尺寸
常规测井预测裂缝且 WellSeismicSupport 低：不新增裂缝片，只允许调整附近已有 DFN
```

这属于 `seismic_prior_v2`，不放入第一版。

### 8.5 验收标准

第一版目标：

```text
AntTrack >= q80 命中率 > lowcoh_steep 当前约 23.6%
AntTrack >= q90 命中率 > lowcoh_steep 当前约 14.7%
Coherence <= q20 命中率不明显低于 lowcoh_steep 当前约 61.7%
Dip < 60° 比例不明显回升
3d_primary 的 AntTrack 高值命中率应明显提升
```

如果 AntTrack 提升但 Coherence 明显下降，调整权重：

```text
AntTrack 0.45, Coherence 0.40, CurvatureMax 0.15
```

如果 Coherence 保持但 AntTrack 提升不明显，调整权重：

```text
AntTrack 0.60, Coherence 0.30, CurvatureMax 0.10
```

如果 Curvature 引入噪声，调整为：

```text
AntTrack 0.55, Coherence 0.40, CurvatureMax 0.05
```

## 9. 执行顺序

严格按以下顺序执行：

1. 新增 `postprocess_density_sgy_seismic_prior.py` 和 Step6B 配置。
2. 编译检查和 JSON 校验。
3. 运行 Step6B，只生成 `SeismicPrior` 和 `DensityOut`。
4. 检查 Step6B summary，确认先验体和密度体合理。
5. 若 Step6B QC 通过，新增 Step7B/Step7C/Step8/Step9 配置。
6. 运行 Step7B。
7. 检查 Step7B patch count、倾角分布、基础对齐统计。
8. 运行 Step7C。
9. 运行 Step8。
