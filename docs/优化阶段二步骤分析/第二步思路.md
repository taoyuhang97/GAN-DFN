# 第二步思路

## 1. 目的

第二步的目标不是直接生成最终 DFN，而是先基于现有成像测井及其井周信息，构造可用于常规测井裂缝预测的专家模型库，并优先输出连续裂缝密度曲线，再在密度曲线基础上细化得到裂缝具体位置。

这里的裂缝位置是密度曲线的后处理结果，不作为第二步的第一输出。

## 2. 当前采用的实现逻辑

### 2.1 专家库划分

当前仍沿用已有的专家模型框架，但不再做基于地震的地层匹配。

专家库按 T6 层位固定拆分为两套：

- T4-T6 使用沙三专家库；
- T6-T7 使用沙四专家库。

其中：

- 沙三专家库保留 5 个模型，对应除车页 1 导眼井以外的 5 个沙三区域成像测井井段；
- 沙四专家库保留 3 个模型，对应沙四地层内的 3 个成像测井井段。

这样处理的前提是：当前任务关注的是 T4-T7 范围内的裂缝分布预测，而不是跨层位的自动识别与匹配。

### 2.2 输入数据组织

第二步的输入分成两类。

第一类是井上的固有属性，包括：

- 岩性分层；
- 常规测井 9 条曲线。

第二类是井周空间属性，包括：

- 地震振幅；
- 曲率体；
- 相干体；
- 蚂蚁体；
- 裂缝反演数据。

如果某些空间属性当前仍缺失，则先按整列留空处理，先把流程跑通，后续数据补齐后再重新训练模型，不在当前阶段临时改写流程结构。

### 2.3 输出顺序

第二步先输出连续裂缝密度曲线。

随后再基于密度曲线进行细化，得到裂缝的具体位置分布。

因此，当前第二步的输出可以理解为两级结果：

1. 主输出：连续裂缝密度曲线；
2. 后处理输出：裂缝具体位置。

### 2.4 样本组织与验证方式

专家模型库的构建仍基于现有成像测井样本，但验证方式做如下约束：

- 车页 1 导眼井作为最终留一井验证井单独提出；
- 其余成像测井井段作为专家模型库的学习样本；
- 在每个分层单一专家构建时，从该层样本中再抽取一口井作为验证井，用于检查该专家是否贴近对应井段的裂缝发育模式。

最终目标是构造出符合不同井段裂缝发育规律的多个专家模型，并在留一井框架下检验泛化能力。

## 3. 主模型 + 原型 + 相似性加权

这一思路可以作为后续优化方向保留到文档中，但当前不作为主实现路线。

原因是当前阶段的样本量有限，且已经有现成的多专家模型基础结构，因此更稳妥的做法是先在现有多模型框架内完成修改和验证。

后续若样本和空间属性补充充分，再考虑：

- 用主模型吸收共性规律；
- 用参考井段原型表达典型裂缝模式；
- 通过相似性加权完成专家选择或结果融合。

## 4. 当前需要坚持的约束

- 不再做基于地震的层位匹配作为主流程；
- T6 作为固定分界，不再动态切分；
- 沙三、沙四专家库数量与当前可用成像井段数量保持一致；
- 空间属性缺失时直接留空，不强行补造；
- 第二步先学密度，再从密度导出位置；
- 车页 1 导眼井只做最终验证，不进入训练集；
- 主模型 + 原型 + 相似性加权只保留为后续探索方向。

## 5. 一句话总结

第二步的核心就是：在固定 T6 分层的前提下，用沙三 5 个、沙四 3 个专家模型，先学习连续裂缝密度曲线，再由密度曲线后处理得到裂缝具体位置，并为后续 GAN 和 DFN 生成提供样本与约束。
