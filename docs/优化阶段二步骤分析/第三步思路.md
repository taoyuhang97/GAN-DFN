# 第三步思路

## 1. 目的

第三步的目标不是直接生成最终 DFN，也不是重新做一次井上裂缝预测，而是围绕真实井构造近井虚拟井控样本，把第二步得到的井上裂缝信息扩展到井周小范围区域。

本步骤的核心作用是：为后续属性-裂缝关系校准、区域裂缝发育带识别和 DFN 生成提供更多局部弱约束样本。

这里的虚拟井控样本不是远场真值替代，也不能与真实井控等价看待。

## 2. 当前采用的实现逻辑

### 2.1 总体定位

第三步的主线可以概括为：

- 以真实井为中心；
- 在井周边小范围内生成候选虚拟井位置；
- 将主地震体和新增属性体信息挂接到这些位置；
- 将第二步的连续裂缝密度曲线扩展成近井虚拟样本的弱标签；
- 为每个虚拟样本附加可信度。

因此，第三步不是“生成完整虚拟测井曲线”的问题，而是“构造近井虚拟井控弱约束样本”的问题。

### 2.2 输入数据组织

第三步的输入主要分为三类。

第一类是基础空间基准，包括：

- 井轨迹；
- 时深关系；
- T4-T7 层位；
- 主地震体；
- 主地震体对应的 `trace_header_xy` 映射；
- 断层数据。

第二类是第二步输出的井控结果，包括：

- 真实井在 T4-T7 范围内的连续裂缝密度曲线；
- 真实井裂缝具体位置；
- 真实井分层结果。

其中连续裂缝密度曲线是第三步最主要的输入，裂缝具体位置主要用于后续细化和结果检查。

第三类是井周空间属性，包括：

- 地震振幅；
- 相干体；
- 蚂蚁体；
- 最大曲率体；
- 最大正曲率体；
- 裂缝反演数据。

这些属性体统一按 `X/Y/T` 与目标位置对齐，不允许跨文件直接按 `trace_idx` 硬对应。

### 2.3 输出顺序

第三步优先输出的是近井虚拟井控样本及其连续裂缝密度弱标签。

因此，当前第三步的输出可以理解为两级结果：

1. 主输出：近井虚拟井样本、多属性序列、连续裂缝密度弱标签、可信度；
2. 后处理输出：必要时再从密度曲线细化得到虚拟井上的裂缝具体位置。

这意味着第三步的主结果不是“完整虚拟测井曲线”，而是“可用于后续建模的近井弱约束样本包”。

### 2.4 当前建议的落地路径

第三步在实现上建议按下面四个环节推进。

第一，围绕真实井生成近井候选位置。

本环节只在真实井周边小范围内选取候选虚拟井位置，不做全区任意扩展。为避免不同实现口径不一致，当前建议先统一采用以下默认规则：

- 先将每口真实井定位到主地震体 `trace_header_xy` 上的最近地震道；
- 以该道为中心，优先选取平面上的 `5x5` 地震道邻域作为近井候选范围；
- 这 `5x5` 邻域共 25 道，其中中心道对应真实井参考位置，其余 24 道作为候选虚拟井位置；
- 若边界区域不足完整 `5x5`，则按实际可用邻域保留；
- 候选位置只在 `T4-T7` 范围内参与后续处理。

这样处理的目的，是先把第三步固定成“围绕真实井、基于主地震网格的近井扩展”，避免一开始就把虚拟井范围扩得过大。

第二，为候选位置挂接主地震和属性体信息。

本环节的目标是把候选虚拟井位置转换成可用样本点。当前建议的统一口径是：

- 时间采样轴先沿用第二步真实井连续裂缝密度曲线的采样轴，不在第三步重新定义新的时间网格；
- 对每个候选虚拟井位置，在每个时间采样点上提取主地震振幅；
- 同时在相同 `X/Y/T` 位置上提取相干体、蚂蚁体、最大曲率体、最大正曲率体和裂缝反演数据；
- 若某属性体在该位置无覆盖，则该属性留空，不强行补值；
- 所有属性体统一按 `X/Y/T` 对齐，不允许跨文件直接按 `trace_idx` 对齐。

通过这一步，每个候选虚拟井都应形成一条与真实井时间轴一致的多属性序列。

第三，将第二步结果扩展为连续裂缝密度弱标签。

本环节不再去拟合新的井上裂缝模型，而是以第二步得到的真实井连续裂缝密度曲线为基础，将其受控扩展到候选虚拟井位置，形成虚拟井上的连续裂缝密度弱标签。当前建议的实现口径是：

- 对每个候选虚拟井，先复制真实井在 `T4-T7` 范围内的时间采样框架；
- 再以真实井连续裂缝密度曲线作为初始参考曲线；
- 然后根据候选位置与真实井之间的距离、层位一致性、断层影响和属性相似性，对密度曲线进行衰减或调整；
- 调整后的结果作为该候选虚拟井的连续裂缝密度弱标签。

也就是说，第三步的重点不是“重新预测一条新曲线”，而是“将第二步结果受控传播到井周邻域”。

第四，附加可信度并输出统一样本包。

由于虚拟井样本不是实测井控，因此每个虚拟样本都需要附带可信度。可信度至少应受距离真实井远近、层位一致性、断层影响和属性相似性控制。为了保证后续步骤可以直接调用，当前建议第三步至少输出以下几类结果：

- 候选虚拟井索引表：记录真实井、候选虚拟井、对应主地震道及空间位置关系；
- 候选虚拟井多属性序列表：记录每个虚拟井在 `T4-T7` 范围内的主地震和属性体采样值；
- 候选虚拟井连续裂缝密度弱标签表；
- 候选虚拟井可信度表；
- 必要时，再补充基于密度曲线细化得到的裂缝具体位置表。

最终输出结果应统一整理成后续步骤可直接调用的样本包，而不是停留在分散的中间文件上。

### 2.5 默认实现口径

为避免不同实现人员在第三步中做出不同版本，当前先固定以下默认实现口径。后续若有新决定，再统一修改。

#### 2.5.1 候选虚拟井的生成单位

第三步当前按“每口真实井”为单位生成候选虚拟井，不按井轨迹上每个采样点单独生成一套候选位置。

默认规则为：

- 每口真实井先在主地震体 `trace_header_xy` 上定位一个中心参考道；
- 以该中心参考道为中心，取平面上的 `5x5` 地震道邻域；
- 共得到 25 道，其中中心道保留为真实井参考位置；
- 其余 24 道作为该口真实井对应的候选虚拟井位置；
- 若位于边界导致不足完整 `5x5`，则按实际存在的邻域道保留；
- 当前第一版先不沿井轨迹逐点扩展，也不生成多套中心参考道。

这样处理的目的是先把第三步固定成“每口真实井对应一组近井候选虚拟井”的口径，避免样本规模和输出结构失控。

#### 2.5.2 属性提取的默认策略

第三步当前统一采用“空间最近邻 + 时间最近样点”的简化策略，不在第一版实现中引入更复杂的空间插值和时间重采样。

默认规则为：

- `X/Y` 位置统一采用最近邻地震道匹配；
- `T` 位置统一采用各属性体自身时间轴上的最近样点；
- 主地震体、相干体、蚂蚁体、曲率体、裂缝反演体全部按这一口径取值；
- 若某属性体在该位置无覆盖，或样点值为缺失值，则该属性单列留空；
- 不因为某一项属性缺失而删除整条虚拟样本；
- 所有属性体仍统一按 `X/Y/T` 对齐，不允许跨文件直接按 `trace_idx` 对齐。

这样处理的目的是先保证第三步样本表结构稳定，再在后续版本中逐步升级到空间插值或统一时间轴。

#### 2.5.3 连续裂缝密度弱标签的第一版生成口径

第三步当前第一版先采用“复制真实井时间轴 + 复制真实井密度曲线 + 距离衰减”的简化方案，不在第一版中同时引入过多调整因素。

默认规则为：

- 每个候选虚拟井先直接沿用对应真实井在 `T4-T7` 范围内的时间采样轴；
- 再以该真实井的连续裂缝密度曲线作为初始参考曲线；
- 第一版只对该曲线施加距离衰减，形成候选虚拟井的连续裂缝密度弱标签；
- 层位约束当前作为硬边界控制，只保留 `T4-T7` 范围内的结果；
- 断层影响和属性相似性当前先作为可信度计算依据保留，不要求在第一版中直接修改密度曲线形状；
- 裂缝具体位置如果需要输出，仍只作为密度曲线的后处理结果。

这样处理的目的是先把第三步最核心的“近井弱标签样本扩展”跑通，再逐步增强其地质约束程度。

#### 2.5.4 可信度的默认粒度

第三步当前默认同时保留两级可信度：

- 井级可信度：用于表征整口候选虚拟井总体可靠性；
- 样点级可信度：用于表征虚拟井在不同时间采样点上的局部可靠性。

若实现难度较高，第一版至少应先保证输出井级可信度；样点级可信度可以先按距离衰减结果给出，再在后续版本中逐步加入更多因素。

#### 2.5.5 输出表的最小字段要求

第三步当前至少应输出四张核心结果表，且每张表的最小字段集合应保持统一。

候选虚拟井索引表至少包括：

- `SourceWellName`
- `VirtualWellName`
- `SourceTraceIdx`
- `VirtualTraceIdx`
- `SourceX`
- `SourceY`
- `VirtualX`
- `VirtualY`
- `DistanceToSource`

候选虚拟井多属性序列表至少包括：

- `VirtualWellName`
- `TIME`
- `X`
- `Y`
- `SEIS_TRUE`
- `COHERENCE`
- `ANT_TRACK`
- `CURVATURE_MAX`
- `CURVATURE_POS`
- `FRACTURE_INV`

候选虚拟井连续裂缝密度弱标签表至少包括：

- `VirtualWellName`
- `TIME`
- `FractureDensityWeak`
- `SourceWellName`
- `DensitySourceType`

候选虚拟井可信度表至少包括：

- `VirtualWellName`
- `WellConfidence`
- `TIME`
- `PointConfidence`

若后续还需补充裂缝具体位置表，则其定位始终是后处理结果表，不替代上述四张核心表。

## 3. 当前需要坚持的约束

- 第三步只做近井样本扩展，不做远场真值生成；
- 第三步主输出是连续裂缝密度弱标签，不是完整虚拟测井曲线；
- 第三步的虚拟井样本不能与真实井同权看待，必须保留可信度；
- 所有新增属性体统一按 `X/Y/T` 对齐，不允许跨文件直接按 `trace_idx` 对齐；
- 裂缝反演数据允许缺覆盖，缺失时可保留为空，不强行补值；
- 裂缝具体位置如果需要输出，只作为密度曲线的后处理结果。

## 4. 与前后步骤的衔接关系

第三步与第二步的关系是：

- 第二步负责把真实井上的裂缝信息预测出来；
- 第三步负责把这些井上结果向井周空间扩展成弱约束样本。

第三步与后续步骤的关系是：

- 第四步使用第三步输出的虚拟井控样本，去校准属性与裂缝发育之间的关系；
- 后续区域裂缝发育带识别和 DFN 生成，也需要参考第三步输出的近井弱约束结果。

因此，第三步是连接“井上结果”和“空间推广”的过渡步骤。

## 5. 一句话总结

第三步的核心就是：围绕真实井，在井周小范围内构造带多属性信息、连续裂缝密度弱标签和可信度的近井虚拟井控样本，为后续属性校准和空间推广提供局部弱约束基础。
