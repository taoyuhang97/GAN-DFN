# 项目实现大框架

## 1. 文档目的

本文档用于固定当前已经收敛后的项目实现大框架，作为后续讨论、数据补充、流程细化和代码调整的统一基线。

本文档只回答三个问题：

1. 当前项目的大方向是什么；
2. 各主要模块在整体流程中的定位是什么；
3. 哪些步骤属于主流程，哪些步骤只是辅助或局部修正。

本文档不是实验方案，不展开到模型细节、参数设置或代码实现。

## 2. 当前大方向

当前项目不再采用“先随机生成离散裂缝片，再依赖地震属性、断层和成像测井进行大规模后修正”的思路。

当前收敛后的主方向是：

- 先统一井、层位、断层、地震体和属性体的数据基准；
- 再建立真实井控和近井虚拟井控；
- 利用井控去校准地震属性、断层与裂缝发育之间的关系；
- 先识别矿区尺度的区域差异和裂缝发育带；
- 再在区级和带级控制下生成初始 DFN；
- 最后只做井旁和局部细节校正，形成可汇报成果。

这意味着：

- 小单元仍然可以保留，但它只是计算单元，不再是主控地质单元；
- 地震属性和断层不只是展示或后处理信息，而是进入前期关系校准和生成控制；
- 成像测井和真实井不是最后才拿来验证，而是前面就参与井控建立和关系校准；
- 近井虚拟测井可以保留，但其角色是“围绕真实井扩充局部弱约束样本”，不是远场真值替代。

## 3. 整体流程

### 第一步：统一数据基准

先将以下数据统一到同一套空间、时间/深度和层位口径下：

- 常规测井；
- 成像测井；
- 井轨迹；
- 时深关系；
- T4-T7 层位；
- 断层；
- 三维地震体；
- 蚂蚁体、相干体、曲率体、裂缝反演等属性体。

本步骤的目标是保证后续所有结果都能在同一套基准中对应和解释。

### 第二步：建立真实井控基准

将成像测井裂缝解释整理为高可信井控结果，提炼每口井、每个层段的：

- 裂缝发育段；
- 裂缝密度；
- 裂缝方向特征。

同时利用成像井对常规井进行约束，得到更多井上的裂缝发育信息。

本步骤的目标是把少量高质量标签扩展为更多井上的裂缝控制点。

### 第三步：构造近井虚拟测井

以真实井为中心，提取周边地震道和属性响应，在结构连续、层位一致、距离受控的前提下构造近井虚拟测井。

本步骤的定位是：

- 扩充真实井附近的局部空间样本；
- 将井控从单条井轨迹扩展到井周围小范围区域；
- 为后续属性-裂缝关系校准提供更多局部弱约束样本。

近井虚拟测井是弱约束样本，不作为强真值替代。

### 第四步：校准属性、断层与裂缝关系

在真实井及其周边虚拟井范围内，分析以下关系：

- 裂缝发育与蚂蚁体、相干体、曲率体、裂缝反演之间的关系；
- 裂缝发育与断层距离之间的关系；
- 这种关系在不同层段、不同区域下是否一致。

本步骤的输出不是直接生成 DFN，而是得到后续空间推广所需的规则、权重和先验认识。

### 第五步：识别区域差异和裂缝发育带

不能直接按小单元独立生成。

在矿区尺度上，需要先识别：

- 哪些区域整体更发育，哪些区域较弱；
- 哪些位置形成连续的裂缝发育带；
- 发育带在不同区域、不同层段上的位置、方向和强弱差异。

这一层用于建立“区级”和“带级”的空间格局。

### 第六步：在区级和带级控制下生成初始 DFN

小单元仍保留，但只作为计算单元。

真正控制初始 DFN 生成的是：

- 所属区域；
- 是否位于裂缝发育带内；
- 距断层远近；
- 属性异常强弱；
- 该层段的真实井控和近井虚拟井控水平。

本步骤的目标是让生成结果从一开始就体现区域差异、带状发育和断层控制，而不是随机铺开。

### 第七步：井旁和局部细节校正

初始 DFN 生成后，再利用成像井、真实井和高可信近井虚拟井结果进行局部修正，包括：

- 井附近偏少则补充；
- 偏多则削弱；
- 局部方向不合理则微调；
- 单元边界和发育带边界做连续性调整。

这一步是局部优化，不应重新塑造整体格局。

### 第八步：一致性检查与汇报输出

最终检查以下问题：

- 不同区域是否表现出明显差异；
- 裂缝发育带是否连续，是否符合断层和属性控制；
- 井附近结果是否与成像解释基本一致；
- 不同层段强弱差异是否合理。

最终输出包括：

- 矿区 DFN；
- 过井剖面；
- 平面裂缝密度图；
- 分层统计；
- 断层距离带统计；
- 井旁对比结果。

## 4. 各模块当前定位

### 4.1 成像测井模块

定位为高可信标签来源和井控基准，不再只是最后验证材料。

### 4.2 常规测井裂缝预测模块

定位为井控扩展模块，用于将少量成像井约束扩展到更多真实井上。

其重点输出应是：

- 裂缝发育段；
- 裂缝密度；
- 分层强弱差异。

不再以逐点裂缝和倾向倾角作为唯一主输出。

### 4.3 近井虚拟测井模块

定位为局部弱约束样本扩展模块。

它服务于：

- 井旁属性-裂缝关系校准；
- 真实井附近空间控制增强；
- 小范围连续性补充。

它不再作为远场真值替代来源。

### 4.4 地震属性与断层模块

定位为前期关系校准和区级/带级控制依据。

它们不是简单的后处理叠加信息，而是参与：

- 属性-裂缝关系校准；
- 裂缝发育带识别；
- 初始 DFN 生成控制；
- 局部一致性检查。

### 4.5 DFN 生成模块

定位为在区级和带级控制下的受约束生成模块。

它不应再主要依赖随机统计参数独立生成，而应在空间先验控制下生成初始 DFN。

### 4.6 后处理与可视化模块

定位为局部优化和汇报交付模块。

其作用是：

- 做井旁和局部细节校正；
- 输出剖面图、平面图、分层统计和三维展示；
- 支撑结果解释和阶段汇报。

## 5. 当前需要坚持的原则

后续细化和实现时，应坚持以下原则：

- 不再把小单元当作主控地质尺度；
- 不再采用“随机生成后大规模后修正”的主线；
- 近井虚拟测井只作为弱约束样本，不作为远场强真值；
- 初始 DFN 必须从生成开始就体现区域差异和裂缝发育带；
- 井控和属性的作用是前面定格局、后面做微调，而不是最后救火；
- 最终成果必须是可解释、可对比、可汇报的矿区结果，而不是仅有三维模型文件。

## 6. 一句话总结

当前项目的大框架已经收敛为：

数据统一 -> 建立真实井控 -> 构造近井虚拟井控 -> 校准属性与断层关系 -> 识别区域和发育带 -> 在区级/带级控制下生成初始 DFN -> 做局部校正 -> 输出汇报成果

后续所有问题细化和模块调整，均以这条主线为基准。
