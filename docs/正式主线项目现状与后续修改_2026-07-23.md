## 3. 当前正式主线总体逻辑

```text
Step1  T4-T7 层位框架和样本分层
  -> Step2  真实井 T4-T7 四表底板
  -> Step3  成像测井强监督样本
  -> Step4  分层、井级专家模型和真实井裂缝密度预测
  -> Step5A 单源虚拟井弱监督扩充
  -> Step5B 真实井与虚拟井统一训练样本
  -> Step6  基础三维密度 + 小/中/大尺度地震解释先验
  -> Step7A/7B/7C 分尺度生成 DFN，Step7D 融合
  -> Step8  成像测井真值和常规测井预测的井控纠偏
  -> Step9  DFN、属性体、地震振幅、层位和断层的一致性展示/QC
```

### 3.1 Step1：层位框架

- 从层位目录选择 T4-T7 文件，把每个样本的 `X/Y` 映射到层位时间。
- 按时间将样本分为 `沙三段=T4-T6`、`沙四段=T6-T7`，T5 作为沙三段内部界面。
- 检查 `T4<T5<T6<T7` 和最小层厚，输出可用性标记。
- 现有样本链仍使用原层位挂接逻辑；7 月 23 日新增的逐道层位表目前主要服务 Step9 展示，尚未改变 Step1-Step8 数据口径。

### 3.2 Step2：真实井正式底板

- 真实井点按自身 `X/Y/TIME` 挂接层位和地震属性，不贴最近地震道。
- 生成点级主表、3x3 井旁上下文、层位边界表和井级 QC 表。
- 只保留 T4-T7 最长连续主段，只允许裁剪主段头尾非法点。

### 3.3 Step3：成像测井强监督

- `Density` 是主监督；`HasFracture` 只是辅助存在标签。
- `GT_POINT_FLAG` 表示原始成像裂缝点映射到样本网格的位置，不能与 `HasFracture` 混用。
- 当前正式输入是 `formal_rebuild/groups/*.csv`，旧总表和旧 Step3 预测基线均不进入主线。

### 3.4 Step4：真实井专家预测

- 按地层分库、按井建立专家实体，输入包含所有现有测井和井旁属性。
- `车页1导眼` 只做 holdout，不进入训练专家。
- 输出连续 `Density`、辅助 `HasFracture` 以及供 Step8 使用的预测裂缝点。

### 3.5 Step5：虚拟井扩充与统一样本

- Step5A 每条虚拟井只允许一个源井，虚拟点属性必须在自身坐标重新采样。
- 距离只控制候选范围和置信度，不直接进入 Density 主公式。
- Step5B 合并真实井预测和单源虚拟井弱监督样本，作为 Step6 基础三维密度模型的唯一训练表。

### 3.6 Step6：多尺度地震解释先验

- 基础三维密度：分沙三、沙四训练 HistGradientBoostingRegressor，在 demo 区输出 X-Y-T 密度 SGY。
- Step6A 小尺度：整理测井/虚拟井推演出的背景裂缝密度。
- Step6B 中尺度：由蚂蚁体主分支和独立的陡倾低相干分支识别裂缝带；曲率作为辅助支持。
- Step6C 大尺度：原始断层面为硬约束，陡倾、垂向连续的低相干异常只能作为补充候选。
- Step6D：生成背景小裂缝密度、中尺度损伤衍生密度、大尺度损伤衍生密度，并保留中大尺度核心供 Step7B/7C 单独构造。

### 3.7 Step7：分尺度 DFN

- Step7A：从 Step6D 三类小尺度密度域按权重采样；方向由分层统计方向族和局部 PCA 共同控制。
- Step7B：在 Step6B component 内采样中尺度裂缝片，片数按 component 体素和分数确定，并拒绝低倾角候选。
- Step7C：保留原始断层 surface fragment，另建 damage-zone patch；推断断裂采用连续 panel group，而不是一个 component 一个大矩形。
- Step7D：按大 > 中 > 小的结构优先级融合，保留 `FractureScale/SourceType` 等来源字段。

### 3.8 Step8：井控纠偏

- Step3 成像测井真值优先使用真实 `Frac_Azimuth/Frac_Dip`。
- Step4 常规测井预测没有真实方向，只能用于井点附近的小尺度补充。
- 当前新增事件聚合逻辑把相邻 Step4 密集采样点合并成井尺度事件，避免一个采样点生成一张裂缝片。
- 井控匹配、模板选择和新增片均限制为 `FractureScale=small`，不改写中大尺度构造主体。

### 3.9 Step9：剖面展示与一致性 QC

- 井控曲剖面定义为：XZ 采样 `(x,Ywell(t),t)`，YZ 采样 `(Xwell(t),y,t)`。
- 中大尺度 DFN 只显示裂缝面与曲剖面的真实交线；小尺度可在限定半宽内投影，以改善剖面过稀问题。
- 可显示 DFN、相干体、蚂蚁体、最大曲率、地震振幅、Step3 成像裂缝真值和原始断层解释。
- 新逐道层位表使 XZ/YZ 每个横向地震道都拥有 T4-T7 曲线，不再依赖 500/900 个稀疏层位采样点。
