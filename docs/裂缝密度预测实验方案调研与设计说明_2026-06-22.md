# 裂缝密度预测实验方案调研与设计说明

## 1. 文档定位

本文档用于说明当前论文实验方案的调研与设计逻辑。它不是实验结果汇报，而是回答以下问题：

1. 本文方法究竟要验证什么计算机问题；
2. 为什么不能只依赖私有油田数据或单一公开数据集；
3. 自建合成数据、公开地震结构数据和私有真实数据分别承担什么验证任务；
4. 每组实验的输入、输出、监督信号、对比方法和评价指标如何设计；
5. 该实验方案如何避免“只在自建规则上验证自己方法”的质疑。

本文档的核心结论是：当前不存在能够完整覆盖“成像测井裂缝解释 + 地震/相干结构属性 + 区域二维裂缝密度真值”的公开数据集。因此，实验需要采用分层验证策略：

自建可公开合成数据：验证完整任务、模块消融和鲁棒性
公开地震结构数据：验证少标签、弱标签、结构传播等可复现机制
私有真实油田数据：验证真实场景下的井位泛化能力

该策略不是把合成数据当作真实油田数据，而是在公开真值缺失的条件下，构造一个可复现、可消融、可定量评价的实验闭环。

## 2. 计算机任务定义

### 2.1 任务表述

本文不宜表述为“根据测井直接预测地下真实裂缝分布”，而应表述为：

> 在极少量一维井控观测和多模态结构图像条件下，进行二维连续密度场预测。

其中，“井控观测”是二维剖面或目标层切片中的少量一维采样位置，不使用“轨迹标签”作为核心术语，避免和计算机领域中的目标轨迹、运动轨迹混淆。

### 2.2 输入与输出

设二维区域为 `Ω`，完整裂缝密度真值为 `Y ∈ [0,1]^(H×W)`。真实训练场景中，模型只能看到少量井控位置上的观测值。

模型输入包括：

| 符号 | 含义 |
|---|---|
| `X` | 多模态结构条件图，包括地震、相干、断层概率、层位距离、曲率等 |
| `Y_w` | 真实井控裂缝密度观测图，非井控位置为空 |
| `M_w` | 真实井控 mask，标记真实监督位置 |
| `Y_v` | 近井虚拟井控弱标签图 |
| `M_v` | 虚拟井控 mask，标记弱监督位置 |
| `C_v` | 虚拟标签置信度图，取值范围 `[0,1]` |

模型学习函数：

```text
Y_hat = f_theta(X, Y_w, M_w, Y_v, M_v, C_v)
```

输出为二维裂缝密度图 `Y_hat`。如果需要评价高裂缝发育区，可由密度图通过阈值派生二值区域，但主任务仍是连续密度预测。

### 2.3 训练目标

仅依赖井控点监督会导致二维无标签区域欠约束，因此训练目标不能只是简单 masked regression。建议采用如下形式：

```text
L_total =
    L_real(Y_hat, Y_w, M_w)
  + lambda_v L_virtual(Y_hat, Y_v, M_v, C_v)
  + lambda_c L_consistency
  + lambda_s L_structure
  + lambda_u L_uncertainty
```

各项含义如下：

| 损失项 | 作用 |
|---|---|
| `L_real` | 在真实井控位置计算强监督回归损失 |
| `L_virtual` | 在虚拟井控位置计算置信度加权弱监督损失 |
| `L_consistency` | 对输入扰动、模态扰动或模型扰动保持预测一致性 |
| `L_structure` | 约束预测结果沿层位或连续结构平滑，在断层/强不连续边界处允许突变 |
| `L_uncertainty` | 对低置信或高不确定区域降低弱标签影响，避免错误增强 |

完整二维真值只在自建合成数据或公开代理任务的测试阶段使用，不在训练阶段暴露。私有真实数据通常没有完整二维真值，因此只进行留一井或留层段评价。

## 3. 方法模块与实验问题对应关系

实验不是孤立列表，而是对方法模块的逐项验证。

| 需要验证的问题 | 对应方法模块 | 核心实验 |
|---|---|---|
| 少量井控观测能否约束二维密度预测 | 稀缺井控 masked regression 框架 | E1 整体有效性 |
| 虚拟井控弱标签是否有效 | 近井弱标签生成与置信度加权监督 | E2 虚拟井控实验 |
| 多模态结构条件是否有效 | 地震/相干/断层/层位等结构条件融合 | E3 多模态结构消融 |
| 极少井控或分布偏置时是否稳定 | 弱标签增强、结构正则和不确定性门控 | E4 稀缺鲁棒性 |
| 方法是否适用于真实油田数据 | 私有数据留一井验证 | E5 私有应用验证 |

这样组织后，实验逻辑从“我们做了很多实验”变为“每个实验对应一个必要的方法主张”。

## 4. 数据支撑方案

### 4.1 理想数据需求与现实缺口

完整实验最理想的数据应包含：

| 数据需求 | 说明 |
|---|---|
| 多模态结构输入 | 地震、相干、断层、层位、曲率等 |
| 成像测井裂缝解释 | 提供真实井控裂缝密度观测 |
| 区域二维裂缝密度真值 | 用于完整二维定量评价 |
| 弱标签或标注置信度 | 用于验证虚拟井控和不确定性控制 |
| 可公开复现划分 | 支撑计算机论文复现实验 |

目前公开数据通常只能覆盖其中一部分，最关键的缺口是缺少“成像测井裂缝解释 + 区域二维裂缝密度真值”。因此，完整任务验证必须依赖自建可公开合成数据，真实应用验证依赖私有数据。

### 4.2 自建可公开合成裂缝密度数据

自建合成数据的定位是 controlled benchmark，用于验证方法机制，而不是替代真实油田数据。

#### 4.2.1 基本生成流程

1. 生成二维地质结构背景  
   构造层位、断层、构造起伏、岩性分区和空间非均质噪声。结构背景可程序生成，也可基于 OpenFWI、Marmousi 等公开结构模型派生。

2. 生成隐藏裂缝密度真值  
   根据断层邻近性、层位曲率、构造梯度、岩性敏感性和空间随机场生成 `Y`：

   ```text
   Y = sigmoid(
       a1 * fault_distance_score
     + a2 * curvature_score
     + a3 * structure_gradient_score
     + a4 * lithology_factor
     + a5 * hidden_random_field
   )
   ```

3. 派生多模态输入  
   从结构背景生成地震图、相干图、断层概率图、层位距离图、曲率图等输入通道。

4. 抽取井控观测  
   在二维区域中采样少量竖直或倾斜井线，只保留井线上的 `Y` 作为训练可见标签，其他区域真值仅用于测试。

5. 生成近井虚拟井控弱标签  
   在真实井附近有限范围内，依据距离、层位方向、断层阻隔和结构连续性生成虚拟标签，并赋予置信度。

#### 4.2.2 避免 circular validation 的设计

自建合成数据最大的风险是：标签由规则生成，输入也由同一批规则派生，模型可能只是学习了人工规则。为降低该风险，合成数据必须加入反偏置设计。

| 风险 | 修改策略 |
|---|---|
| 输入变量直接决定标签 | 保留隐藏因子，不把所有标签生成因子都作为输入 |
| 训练和测试规则完全一致 | 设置分布内、扰动分布和 OOD 分布三类测试 |
| 单一公式过于简单 | 使用多套生成器和随机参数范围 |
| 结构输入过于干净 | 对地震、相干、断层概率、层位图加入噪声、模糊、缺失和错位 |
| 模型只学习断层附近高密度 | 加入非断层控制裂缝区、弱构造裂缝区和低对比异常区 |

建议将合成测试分为三组：

| 测试类型 | 说明 | 目的 |
|---|---|---|
| ID 测试 | 训练和测试使用同一生成器不同随机种子 | 验证基本学习能力 |
| Perturbation 测试 | 增加噪声、模态缺失、井控误差、结构错位 | 验证抗扰动能力 |
| OOD 测试 | 改变断层样式、层位形态、裂缝控制因子或生成器 | 验证泛化能力，降低规则过拟合质疑 |

### 4.3 公开数据集及可执行代理任务

公开数据不能直接证明真实裂缝密度预测效果，但可以验证与本文方法相关的计算机机制。文档中不应只写“可支撑机制验证”，而要明确每个公开数据集对应什么代理任务。

| 数据集 | 提供内容 | 可执行代理任务 | 验证机制 | 不能证明的内容 |
|---|---|---|---|---|
| OpenFWI | 合成地震数据与速度/结构模型，包含 fault、interface、CO2 reservoir 等结构类型 | 从少量一维采样和结构图像恢复二维速度/结构属性 | 少标签二维场重建、多模态结构约束、OOD 测试 | 不能证明真实裂缝密度预测 |
| FaultSeg3D | 合成地震图像与断层标签 | 只保留少量线状/点状断层标注，恢复完整断层图 | 稀缺监督、结构传播、弱监督对比 | 不是裂缝密度任务 |
| CRACKS | F3 地震断层标注，包含不同水平标注者和置信度 | 用低质量标注作为弱标签，专家标注作为评价 | 弱标签、噪声标签、置信度门控 | 没有井控裂缝密度 |
| Thebe | 真实地震断层检测 benchmark 数据 | 少标签断层识别和跨域测试 | 真实地震结构泛化 | 不是裂缝密度任务 |
| Netherlands F3 | 公开 3D 地震、层位、少量井测井、地震相解释 | 井震对齐、多模态结构输入、层位约束辅助任务 | 多模态输入组织和结构条件消融 | 无成像测井裂缝解释和裂缝密度真值 |
| Penobscot | 公开 3D 地震、层位、少量井测井、地震相解释 | 井震结合和地震相/结构辅助任务 | 多模态结构建模 | 无裂缝密度真值 |

这些公开数据的作用是补充可复现代理验证，不能在论文中表述为“公开数据直接验证了地下裂缝密度预测”。

### 4.4 私有真实数据

私有数据用于真实场景适用性验证。可使用：

1. 成像测井裂缝解释结果；
2. 井旁地震、相干、断层、层位等结构属性；
3. 留一井或留层段验证方式；
4. 匿名 MAE、RMSE、R²、Pearson、Spearman 等指标。

私有数据验证能说明模型对未参与训练井位的预测能力，但不能单独证明完整二维预测图全局正确。因此，应明确其作用边界。

### 4.5 实验步骤与数据使用矩阵

为避免数据使用逻辑分散，建议将实验步骤和数据来源明确绑定。整体原则是：自建合成数据承担完整裂缝密度任务验证，公开数据承担可复现代理任务验证，私有数据承担真实应用验证。

| 实验 | 主数据 | 辅助数据 | 数据具体用法 | 能证明什么 | 不能证明什么 |
|---|---|---|---|---|---|
| E1 整体有效性 | 自建合成裂缝密度数据 | 私有真实数据 | 合成数据提供完整二维真值，用于训练时隐藏、测试时评价；私有数据做留一井指标验证 | 方法能否在少量井控条件下恢复二维密度场；真实井位泛化是否有效 | 私有数据无法证明完整二维图处处正确 |
| E2 虚拟井控弱标签 | 自建合成裂缝密度数据 | CRACKS、私有真实数据 | 合成数据直接计算虚拟标签误差；CRACKS 用低质量/多置信度断层标注验证弱标签门控；私有数据观察加入虚拟井控后的留一井变化 | 虚拟井控是否有效，置信度是否能抑制错误弱标签 | CRACKS 不能证明裂缝密度预测，只能证明弱标签机制 |
| E3 多模态结构消融 | 自建合成裂缝密度数据 | OpenFWI、F3 Netherlands、Penobscot、私有真实数据 | 合成数据逐步去除地震/相干/断层/层位通道；OpenFWI 验证结构约束场重建；F3/Penobscot 验证真实井震多模态输入组织；私有数据验证模态消融下留一井指标 | 多模态结构条件是否提升空间预测，哪些模态贡献更大 | F3/Penobscot 无裂缝密度真值，不能做主任务定量评价 |
| E4 稀缺观测鲁棒性 | 自建合成裂缝密度数据 | FaultSeg3D、CRACKS、Thebe | 合成数据控制井数、标签比例、井位偏置和噪声；公开断层数据构造少标签/弱标签结构代理任务 | 方法在少井、少标签、偏置标签和噪声条件下是否更稳定 | 断层代理任务不能直接等同裂缝密度任务 |
| E5 私有真实验证 | 私有真实油田数据 | 无，或仅使用公开数据预训练/参数参考 | 使用真实成像测井裂缝解释和地震/相干/构造属性，进行 leave-one-well-out 和 leave-one-interval-out | 方法在真实场景下对未见井/未见层段的预测能力 | 不能公开原始图像，不能直接验证完整二维区域真值 |

各数据集在实验中的具体定位如下：

| 数据来源 | 在本文实验中的角色 | 推荐使用方式 |
|---|---|---|
| 自建合成裂缝密度数据 | 主验证数据 | 用于 E1-E4 的主结果、消融、鲁棒性、OOD 测试 |
| OpenFWI | 结构场重建代理数据 | 从速度/结构模型中抽取少量一维采样，验证少标签二维场重建和结构约束 |
| FaultSeg3D | 合成断层代理数据 | 将完整断层标签降采样为少量线状/点状标注，验证稀缺监督传播 |
| CRACKS | 弱标签/置信度代理数据 | 使用不同质量标注和置信度信息，验证不可靠弱标签处理 |
| Thebe | 真实地震结构泛化数据 | 用于少标签断层识别和跨域泛化代理实验 |
| F3 Netherlands | 真实井震多模态组织数据 | 用于验证地震、层位、井数据的输入组织和结构条件构造 |
| Penobscot | 真实井震多模态组织数据 | 用于多模态结构输入、井震结合辅助任务 |
| 私有真实油田数据 | 应用验证数据 | 用于 E5 留一井/留层段验证，只公开匿名指标 |

## 5. 虚拟井控弱标签构造协议

虚拟井控是本文实验中最容易被质疑的部分，必须写成可复现算法，而不是概念描述。

### 5.1 构造原则

1. 只在真实井附近有限范围内生成；
2. 不跨越断层或强结构不连续边界；
3. 优先沿层位方向或局部构造连续方向传播；
4. 距离越远置信度越低；
5. 构造复杂、模态冲突或模型不确定区域降低置信度；
6. 虚拟井控只能作为弱标签，不参与真实标签统计。

### 5.2 置信度定义

可将虚拟标签置信度定义为：

```text
C_v(p) = w_d(p) * w_s(p) * b_f(p) * w_u(p)
```

其中：

| 项 | 含义 |
|---|---|
| `w_d(p)=exp(-d(p)/r)` | 距离权重，距离真实井越远越低 |
| `w_s(p)` | 结构连续性权重，沿层位或相似结构方向较高 |
| `b_f(p)` | 断层阻隔项，跨断层或强不连续边界时取 0 或低值 |
| `w_u(p)` | 不确定性权重，高不确定区域降低权重 |

虚拟标签值可由真实井控观测沿结构方向传播或局部插值得到，训练时通过 `C_v` 加权，不作为真实标签使用。

### 5.3 需要验证的问题

虚拟井控实验必须验证三点：

1. 带置信度的虚拟井控是否优于无虚拟井控；
2. 无权重或过范围虚拟井控是否可能带来负迁移；
3. 置信度是否与虚拟标签误差存在合理相关性。

## 6. 实验分组设计

### 6.1 E1 整体有效性实验

目标：验证完整方法在少量井控观测和多模态结构条件下能否预测二维密度场。

| 项目 | 设计 |
|---|---|
| 主数据 | 自建合成数据 |
| 补充数据 | 私有真实数据留一井验证 |
| 输入 | `X, Y_w, M_w, Y_v, M_v, C_v` |
| 输出 | 二维连续裂缝密度图 |
| 训练监督 | 真实井控强监督 + 虚拟井控弱监督 + 一致性/结构正则 |
| 合成评价 | 完整二维真值上的 MAE、RMSE、R²、Pearson、SSIM、高发育区 F1/IoU |
| 私有评价 | 留一井 MAE、RMSE、R²、Pearson、Spearman |

E1 必须包含 ID、Perturbation 和 OOD 三类合成测试，避免只在单一合成规则上取得好结果。

数据使用说明：

1. 自建合成数据是 E1 的主数据。训练时只使用少量井控观测和虚拟井控弱标签，完整二维裂缝密度图只用于测试评价。
2. 私有真实数据只用于补充验证。采用 leave-one-well-out，在被留出井位置计算误差，不展示原始剖面和坐标。
3. OpenFWI 可作为扩展代理数据，用于验证从少量一维采样恢复二维结构场的能力，但不作为裂缝密度主实验。

### 6.2 E2 虚拟井控弱标签实验

目标：验证虚拟井控的有效性和风险边界。

| 组别 | 设置 | 目的 |
|---|---|---|
| A | 只用真实井控 | 基础性能 |
| B | 真实井控 + 无权重虚拟井控 | 验证直接扩样本是否可靠 |
| C | 真实井控 + 距离权重 | 验证局部性假设 |
| D | 真实井控 + 距离 + 结构边界 | 验证断层/层位约束 |
| E | 真实井控 + 距离 + 结构边界 + 不确定性门控 | 验证完整弱标签机制 |
| F | 过范围虚拟井控 | 验证无约束增强风险 |

主指标包括：最终预测 RMSE、虚拟标签误差、误差-距离曲线、置信度-误差 Spearman 相关性、错误增强导致的性能退化。

数据使用说明：

1. 自建合成数据用于直接验证虚拟井控质量。因为合成数据有完整二维真值，可以计算每个虚拟标签与真值之间的误差。
2. CRACKS 用于弱标签机制代理验证。可将低经验标注者或低置信度标注视为弱标签，将专家标注作为评价参考，验证置信度门控是否能抑制不可靠标注。
3. 私有真实数据用于间接验证虚拟井控是否提升留一井指标，但不能直接计算虚拟井控在全区域的真实误差。

### 6.3 E3 多模态结构条件消融实验

目标：验证结构条件是否提供有效空间约束，而不是模型只进行平滑外推。

| 组别 | 输入条件 |
|---|---|
| A | 井控观测 + mask |
| B | 井控 + 地震 |
| C | 井控 + 相干 |
| D | 井控 + 断层/层位 |
| E | 井控 + 地震 + 相干 |
| F | 井控 + 全部结构条件 |
| G | 井控 + 全部结构条件 + 虚拟井控 |

评价除全局误差外，还应包含断层附近误差、层位边界附近误差、高密度区 IoU/F1 和 SSIM。该实验主要由自建合成数据支撑，OpenFWI、F3、Penobscot 可作为结构代理任务补充。

数据使用说明：

1. 自建合成数据用于主消融。逐步加入或移除地震、相干、断层概率、层位距离、曲率等通道，评价完整二维真值误差。
2. OpenFWI 用于结构约束代理实验。可从速度/结构模型派生结构通道，抽取少量一维采样，验证结构条件对二维场重建的帮助。
3. F3 Netherlands 和 Penobscot 用于真实井震多模态输入组织验证，重点检查地震、层位、井数据如何对齐和转化为模型输入。
4. 私有真实数据用于真实模态消融。只报告不同输入组合下的留一井指标，不公开图像。

### 6.4 E4 稀缺观测鲁棒性实验

目标：验证井控数量少、分布偏、观测不完整时方法是否退化更慢。

| 设置 | 具体做法 |
|---|---|
| 井数变化 | 使用 1、2、3、5 口井作为监督 |
| 标签比例变化 | 保留 5%、10%、20%、50% 的井控点 |
| 空间偏置 | 井集中在一侧、中心、边缘或均匀分布 |
| 噪声干扰 | 给井控密度加入不同强度噪声 |
| 层段缺失 | 删除部分井段标签，模拟解释不完整 |

结果应以曲线和统计图呈现，包括 RMSE-井数曲线、F1-标签比例曲线、性能方差和最差情况误差。FaultSeg3D、CRACKS、Thebe 可用于少标签结构代理任务。

数据使用说明：

1. 自建合成数据用于主鲁棒性实验。通过控制井数、标签比例、井位空间分布、观测噪声和井段缺失，生成可重复的鲁棒性曲线。
2. FaultSeg3D 用于少标签结构传播代理实验。将完整断层标签降采样为少量线状或点状监督，比较不同方法恢复完整断层图的能力。
3. CRACKS 用于弱标签质量变化实验。利用不同标注质量和置信度信息，验证方法在不可靠标签条件下是否稳定。
4. Thebe 用于真实地震结构泛化实验，验证方法在真实地震结构数据上的少标签适应能力。

### 6.5 E5 私有真实数据验证

目标：验证方法在真实油田场景中的井位泛化能力。

| 项目 | 设计 |
|---|---|
| 验证方式 | leave-one-well-out，必要时增加 leave-one-interval-out |
| 训练 | 使用其余井控数据和结构条件 |
| 测试 | 在被留出井或留出层段上评价 |
| 指标 | MAE、RMSE、R²、Pearson、Spearman、分强度区间误差 |
| 可公开内容 | 匿名统计指标、均值和方差 |
| 不公开内容 | 原始剖面、坐标、井名、原始地震、原始测井 |

私有验证应明确说明：它验证的是井位/层段泛化能力，不直接证明整张二维预测图处处正确。

数据使用说明：

1. E5 只使用私有真实油田数据作为验证对象。
2. 可使用公开数据或合成数据进行预训练、参数初始化或方法调试，但最终真实验证必须严格在私有数据留一井/留层段协议下完成。
3. 输出内容应限制为匿名统计指标，包括每口留出井的误差、均值、方差和分裂缝强度区间误差。
4. 如果允许补充脱敏定性材料，应仅展示经过裁剪、归一化和去坐标化的局部统计图，不能展示原始剖面和井位。

## 7. 对比方法设置

对比方法需要收缩为可实现、可公平适配的强基线，而不是堆叠方法名称。

### 7.1 主基线

| 类型 | 方法 | 适配方式 |
|---|---|---|
| 地质统计/空间估计 | Regression Kriging、Co-Kriging | 用井控观测和结构属性进行空间估计 |
| 常规深度回归 | U-Net masked regression | 只在井控位置计算监督损失 |
| Transformer/现代分割骨干 | SegFormer 或 Swin-UNet masked regression | 改为连续密度回归输出 |
| 半监督学习 | Mean Teacher | 使用结构图像扰动一致性和井控监督 |
| 伪标签/不可靠标签学习 | U2PL 或 UniMatch | 适配为稀缺监督下的伪标签/一致性学习 |
| 稀疏标注方法 | scribble/partial-label 方法 | 用井控线状标注作为稀疏监督 |

### 7.2 代理任务基线

| 方法 | 使用范围 |
|---|---|
| FaultSSL | 公开断层结构少标签代理任务 |
| FaultSeg 类方法 | FaultSeg3D 等断层代理任务 |
| Seismic Fault SAM | 公开地震断层识别代理任务 |

这些方法不应直接作为裂缝密度回归主基线，而应在公开结构代理任务中使用。

### 7.3 消融基线

| 消融版本 | 验证内容 |
|---|---|
| 无虚拟井控 | 虚拟弱标签是否有效 |
| 无置信度权重 | 置信度门控是否有效 |
| 无结构边界约束 | 断层/层位约束是否有效 |
| 无一致性正则 | 半监督一致性是否有效 |
| 单模态输入 | 多模态结构条件是否有效 |

## 8. 评价指标协议

指标需要绑定实验问题，而不是泛泛罗列。

| 实验 | 主指标 | 辅助指标 |
|---|---|---|
| E1 整体有效性 | MAE、RMSE、R²、Pearson | SSIM、高发育区 F1/IoU |
| E2 虚拟井控 | 虚拟标签误差、置信度-误差 Spearman、性能增益/退化 | 误差-距离曲线 |
| E3 多模态结构 | 边界区域误差、高发育区 IoU/F1、SSIM | 全局 MAE/RMSE |
| E4 稀缺鲁棒性 | RMSE-井数曲线、F1-标签比例曲线、性能方差 | 最差情况误差 |
| E5 私有验证 | 留一井 RMSE、Pearson、Spearman | 分强度区间误差、均值和方差 |

高发育区指标需要明确阈值来源，例如使用训练集分位数、固定密度阈值或领域定义阈值。SSIM、IoU 等二维指标只适用于有完整二维真值的合成数据或公开代理任务，不适用于无完整二维真值的私有数据。

## 9. 实验逻辑总结

修改后的实验逻辑可以概括为：

```text
E1：在可控完整真值上证明整体方法有效
E2：证明虚拟井控是受控弱标签，而不是伪真实标签
E3：证明多模态结构条件确实帮助二维空间传播
E4：证明极少井控、偏置井控和噪声井控下方法更稳定
E5：在私有真实数据上验证未见井/未见层段的泛化能力
```

该逻辑相比初版没有推翻“三层数据 + 五组实验”的框架，但做了三点关键增强：

1. 自建合成数据增加 ID、扰动和 OOD 测试，降低规则过拟合质疑；
2. 公开数据不再被笼统说成“验证裂缝预测”，而是转化为明确代理任务；
3. 训练目标从简单井控点回归升级为“真实井控监督 + 置信度弱监督 + 一致性正则 + 结构约束 + 不确定性控制”。

## 10. 后续实施计划

建议后续按以下顺序推进：

1. 固化任务定义和输入输出格式；
2. 设计自建合成数据生成器，并明确 ID、扰动和 OOD 测试划分；
3. 明确虚拟井控生成算法和置信度计算方式；
4. 选择 3-5 个主基线并确认代码来源及适配方式；
5. 确定公开数据代理任务，包括 OpenFWI、FaultSeg3D、CRACKS 等数据的具体输入输出；
6. 先完成 E1/E2 合成实验，再补充 E3/E4 代理任务；
7. 最后完成 E5 私有数据 leave-one-well-out 和 leave-one-interval-out 验证。

## 11. 对外表述建议

建议对外这样概括实验方案：

> 由于公开数据中缺少完整的成像测井裂缝解释与区域二维裂缝密度真值，本文采用分层实验验证策略。首先构建可公开的受控合成基准，在完整真值条件下验证稀缺井控、多模态结构约束和近井弱标签增强机制；其次在公开地震结构数据上构造少标签、弱标签和结构传播代理任务，验证方法机制的可复现性；最后在私有真实油田数据上进行匿名留一井和留层段验证，评估方法在真实场景中的适用性。

需要避免的表述：

1. 不应说“合成数据证明真实地下裂缝预测准确”；
2. 不应说“公开断层数据直接验证裂缝密度预测”；
3. 不应把虚拟井控称为真实标签；
4. 不应只报告私有留一井指标而缺少公开可复现实验；
5. 不应只和 Kriging、CNN 等弱基线比较。

最终应强调：本文实验方案的目标是形成“机制可复现、模块可消融、真实场景可验证”的完整证明链。

## 12. 开源框架推荐与实现路线

计算机领域论文通常不会从零实现所有模块，而是在已有强基线或公开框架上进行改造，并在统一训练协议下验证新增模块的贡献。对于本文任务，更合理的路线不是寻找“裂缝预测专用代码”，而是选择弱监督/半监督 dense prediction 框架作为底座，再加入井控 mask、虚拟井控弱标签、置信度门控和多模态结构输入。

### 12.1 首选主框架：UniMatch V2

| 项目 | 内容 |
|---|---|
| 论文 | UniMatch V2: Pushing the Limit of Semi-Supervised Semantic Segmentation |
| 发表 | TPAMI 2025 |
| 代码 | https://github.com/LiheYoung/UniMatch-V2 |
| 推荐程度 | 最高，建议作为主工程底座 |

推荐原因：

1. 属于近年高质量半监督语义分割框架，计算机领域认可度高；
2. 官方代码包含 supervised、FixMatch、UniMatch V2 等训练协议，便于做公平对比；
3. 使用 DINOv2 encoder，具备较强特征表达能力；
4. 可以将 segmentation head 改为连续密度回归 head；
5. 适合接入真实井控 mask、虚拟井控 mask、置信度权重和多模态结构通道。

建议改造路线：

```text
UniMatch V2
+ 多通道地震/相干/断层/层位输入
+ masked regression loss
+ 虚拟井控置信度加权 weak loss
+ 结构一致性/扰动一致性约束
= 本文主方法框架
```

### 12.2 强相关基线：U2PL

| 项目 | 内容 |
|---|---|
| 论文 | Semi-Supervised Semantic Segmentation Using Unreliable Pseudo-Labels |
| 发表 | CVPR 2022，扩展版 IJCV 2024 |
| 代码 | https://github.com/Haochen-Wang409/U2PL |
| 推荐程度 | 高，适合作为强基线或弱标签思想参考 |

推荐原因：

1. 核心思想是利用 unreliable pseudo-label，与本文“虚拟井控是低置信弱标签”的逻辑接近；
2. 可用于对比本文的置信度加权弱监督机制；
3. 能支撑“低可信伪标签如何参与训练”的计算机方法讨论。

需要注意：

1. 原方法是分类分割任务，需要改造成连续密度回归或高发育区分割；
2. 不建议作为主工程底座，作为强基线更合适。

### 12.3 稀疏标注参考：Scribbles4All

|---|---|
| 论文 | Scribbles for All |
| 发表 | NeurIPS 2024 |
| 代码 | https://github.com/wbkit/Scribbles4All |
| 推荐程度 | 中高，适合作为稀疏线状标注实验参考 |

推荐原因：

1. 研究 scribble-supervised segmentation，与本文井控观测在二维图上呈现的稀疏线状监督有相似性；
2. 提供从完整标注生成 scribble 弱标签的工具，可参考其稀疏标注构造方式；
3. 适合用于公开代理任务和稀疏标注实验设计。

需要注意：

1. 原任务是分割，不是连续密度回归；
2. 更适合作为实验协议和弱监督基线参考，不适合作为主模型底座。

### 12.4 Transformer 半监督基线：AllSpark

| 项目 | 内容 |
|---|---|
| 论文 | AllSpark: Reborn Labeled Features from Unlabeled in Transformer for Semi-Supervised Semantic Segmentation |

推荐原因：

2. 强调 labeled/unlabeled feature 交互，可作为强半监督对比；
3. 能提高计算机领域实验对比的说服力。

需要注意：

2. 与本文虚拟井控机制不是直接对应关系；

### 12.5 地震结构代理任务参考：FaultSeg3D

| 项目 | 内容 |
|---|---|

| 发表 | GEOPHYSICS 2019 |
| 代码 | https://github.com/xinwucwp/faultSeg |
| 推荐程度 | 辅助，适合地震结构代理任务 |

推荐原因：

1. 是地震断层分割领域常用公开代码；
2. 包含合成地震图像和断层标签的生成/训练思路；
3. 可作为公开结构代理任务和合成地震结构构造的参考。

需要注意：

1. 不是近年方法；
2. 不是半监督方法；
3. 不是裂缝密度预测；
4. 不适合作为计算机论文主底座。

### 12.6 推荐实现策略

建议采用如下实现路线：

1. 以 UniMatch V2 作为主工程底座；
2. 将分类分割输出改为连续密度回归输出；
3. 加入真实井控 `M_w` 下的 masked regression loss；
4. 加入虚拟井控 `M_v` 和置信度 `C_v` 下的 weak loss；
5. 扩展输入通道，接入地震、相干、断层概率、层位距离等结构条件；
6. 保留 UniMatch V2/FixMatch/supervised 训练协议作为内部公平对比；
7. 将 U2PL、Scribbles4All、AllSpark 作为强基线或代理任务参考；
8. 将 FaultSeg3D 用于公开地震断层代理任务和合成结构数据参考。

对应论文表述可以写为：

> 本文基于近年半监督 dense prediction 框架构建主模型，将原有分类分割任务扩展为稀缺井控条件下的连续密度场预测，并引入结构约束虚拟井控、置信度加权弱监督和多模态结构条件融合模块。

该路线的优势是：避免从零实现完整深度学习框架，同时能够在计算机领域认可的强基线协议下证明本文新增模块的有效性。

## 13. 实现实验协议

本章用于把前述实验方案进一步落到可实施层面，明确哪些实验必须完成、数据如何生成、模型如何改造、基线如何公平比较、指标如何计算。该章节可以作为后续代码实现和实验排期的依据。

### 13.1 最小可实施实验闭环

完整方案包含 E1-E5，但如果全部同时推进，工作量过大。建议先形成一个最低可发表闭环，再逐步补充公开代理任务和扩展验证。

| 优先级 | 实验 | 是否必须 | 作用 |
|---|---|---|---|
| P0 | E1 合成主实验 | 必须 | 证明完整方法在有二维真值的受控任务上有效 |
| P0 | E2 虚拟井控消融 | 必须 | 证明虚拟井控弱标签和置信度门控有效 |
| P0 | E3 多模态消融 | 必须 | 证明结构条件确实提供增益 |
| P0 | E5 私有留一井验证 | 必须 | 证明真实场景下未见井预测能力 |
| P1 | E4 稀缺鲁棒实验 | 强烈建议 | 证明少井控、偏置井控条件下方法稳定 |
| P1 | OpenFWI 代理任务 | 建议 | 补充少标签二维场重建的公开可复现验证 |
| P2 | FaultSeg3D/CRACKS/Thebe 代理任务 | 可选增强 | 补充结构传播、弱标签和真实地震泛化验证 |
| P2 | F3/Penobscot 多模态组织实验 | 可选增强 | 补充真实井震多模态输入组织说明 |

最低可发表实验闭环建议为：

```text
E1 合成主实验
+ E2 虚拟井控消融
+ E3 多模态消融
+ E5 私有 leave-one-well-out
```

若时间和数据处理条件允许，再补充 E4 和公开代理任务，以增强计算机领域论文的可复现性和说服力。

### 13.2 自建合成数据生成协议

自建合成数据需要固定生成规则、参数范围和划分方式，避免实验不可复现。

建议初始版本采用如下设置：

| 项目 | 建议设置 |
|---|---|
| 图像尺寸 | `256×256` 起步，后续可扩展到 `512×512` |
| 样本数量 | 训练 1000-3000，验证 200-500，测试 500-1000 |
| 数据划分 | ID 测试、Perturbation 测试、OOD 测试分开保存 |
| 输入通道 | 地震/结构图、相干图、断层概率图、层位距离图、曲率图、井控图、mask、虚拟井控图、置信度图 |
| 输出真值 | 单通道连续裂缝密度图，归一化到 `[0,1]` |
| 井数设置 | 默认 3 口井；鲁棒性实验使用 1、2、3、5 口井 |
| 井形态 | 竖直井为主，补充少量倾斜井 |
| 井控噪声 | 默认无噪声，扰动测试加入 5%、10%、20% 噪声 |
| 训练标签 | 只保留井控位置和虚拟井控位置，完整真值不参与训练 |

合成数据建议保存为统一格式：

```text
sample_id/
  x.npy              # 多模态结构输入
  y_full.npy         # 完整二维裂缝密度真值，仅测试/评价使用
  y_well.npy         # 真实井控观测图
  mask_well.npy      # 真实井控 mask
  y_virtual.npy      # 虚拟井控弱标签
  mask_virtual.npy   # 虚拟井控 mask
  conf_virtual.npy   # 虚拟井控置信度
  meta.json          # 生成参数、井数、噪声、测试类型等
```

合成数据至少需要提供三类测试集：

| 测试集 | 构造方式 | 目的 |
|---|---|---|
| ID | 与训练集同生成器，不同随机种子 | 验证基本拟合能力 |
| Perturbation | 输入模态加噪声、缺失、错位，井控加噪声 | 验证抗扰动能力 |
| OOD | 改变断层样式、层位形态、裂缝控制因子或生成器 | 验证规则外泛化能力 |

需要注意：输入通道不能完全等同于裂缝密度生成公式中的所有因子。应保留隐藏随机场或隐藏控制因子，避免模型通过简单映射直接恢复标签。

### 13.3 虚拟井控生成实现协议

虚拟井控生成应实现为独立模块，输入真实井控、结构条件和断层/层位信息，输出虚拟标签、mask 和置信度。

建议初始实现如下：

| 项目 | 建议设置 |
|---|---|
| 有效半径 `r_max` | 5-20 个像素，作为超参数消融 |
| 距离度量 `d(p)` | 初始使用欧氏距离，后续可扩展为沿层位方向的地质距离 |
| 距离权重 | `w_d(p)=exp(-d(p)/r)` |
| 结构连续性 `w_s` | 根据层位方向一致性、相干相似性或局部结构相似度计算 |
| 断层阻隔 `b_f` | 断层概率高于阈值或传播路径跨断层时置 0 或降权 |
| 不确定性权重 `w_u` | 初始可由规则不确定性给出，后续可由模型预测方差或 MC Dropout 得到 |
| 虚拟标签值 `Y_v` | 从最近真实井控点沿结构方向传播，或使用局部加权插值得到 |

建议伪代码：

```text
for each real well observation q:
    for each candidate point p within r_max:
        if path(q, p) crosses fault:
            continue
        y_virtual[p] = structure_guided_interpolation(q, p)
        conf[p] = exp(-d(q,p)/r) * w_s(p) * b_f(p) * w_u(p)
        mask_virtual[p] = 1 if conf[p] > tau else 0
```

训练策略建议：

1. 前若干 epoch 只使用真实井控监督，作为 warm-up；
2. 模型预测相对稳定后再启用虚拟井控 weak loss；
3. 虚拟井控损失权重 `lambda_v` 从小到大逐步增加；
4. 对低置信度虚拟标签只作为弱监督，不参与真实标签统计；
5. E2 中必须测试无权重、距离权重、结构边界、完整置信度和过范围增强版本。

### 13.4 UniMatch V2 改造协议

若采用 UniMatch V2 作为主框架，需要完成以下改造。

| 原框架模块 | 改造方式 |
|---|---|
| RGB 输入 | 改为多通道输入，包括结构图、井控图、mask、虚拟井控图、置信度图 |
| 分类输出 head | 改为单通道连续密度回归 head |
| 交叉熵损失 | 改为 masked L1、masked MSE 或 SmoothL1 |
| 伪标签分类置信度 | 改为连续预测不确定性或弱标签置信度 |
| segmentation evaluation | 保留密度回归指标，并额外派生高发育区分割指标 |
| consistency loss | 从类别一致性改为连续密度图一致性 |

建议损失实现：

```text
L_real = mean( M_w * loss(Y_hat, Y_w) )
L_virtual = mean( M_v * C_v * loss(Y_hat, Y_v) )
L_consistency = mean( || f(aug_1(input)) - f(aug_2(input)) || )
L_total = L_real + lambda_v L_virtual + lambda_c L_consistency + lambda_s L_structure
```

如果不确定性模块短期难以实现，可以先采用规则置信度 `C_v` 完成第一版实验；后续再加入 MC Dropout、深度集成或方差预测 head 作为增强版本。

### 13.5 基线公平性协议

为了避免对比不公平，所有基线应尽量遵守统一协议。

| 规则 | 要求 |
|---|---|
| 数据划分 | 所有方法使用相同训练/验证/测试划分 |
| 输入模态 | 主实验中所有深度模型使用相同结构输入；特殊消融实验除外 |
| 井控监督 | 所有方法使用相同真实井控 `Y_w, M_w` |
| 虚拟井控 | 若比较完整方法与无虚拟版本，需明确虚拟标签只属于本文模块；若比较半监督基线，应可给基线提供相同弱标签或伪标签预算 |
| backbone | 尽量使用相同或相近 backbone；若不同，需要报告参数量和训练设置 |
| 训练轮数 | 使用相同 epoch、batch size、优化器或等价训练预算 |
| 随机种子 | 每个实验至少 3 个随机种子，报告均值和标准差 |
| 超参数选择 | 在验证集上选择，不使用测试集调参 |

建议基线分为三组执行：

1. 空间估计基线：Regression Kriging、Co-Kriging；
2. 深度回归基线：U-Net masked regression、SegFormer/Swin-UNet masked regression；
3. 弱/半监督基线：Mean Teacher、UniMatch V2 baseline、U2PL 或 scribble 方法适配版本。

对于难以完整适配的基线，应明确其使用范围。例如，Seismic Fault SAM、FaultSSL 等只用于公开断层代理任务，不作为裂缝密度回归主基线。

### 13.6 指标计算协议

指标计算需要明确评价区域和统计方式。

| 指标 | 计算范围 | 说明 |
|---|---|---|
| MAE/RMSE | 合成数据上全图或非训练井区域；私有数据上留出井/层段 | 主数值误差 |
| R² | 同 MAE/RMSE | 衡量解释方差 |
| Pearson/Spearman | 合成全图或私有留出井采样点 | 衡量趋势一致性 |
| SSIM | 仅用于有二维真值的合成数据或代理任务 | 衡量空间结构相似性 |
| F1/IoU/PR-AUC | 高发育区二值图 | 阈值需固定 |
| 置信度-误差相关性 | 虚拟标签位置 | 建议使用 Spearman |
| 性能方差 | 多随机种子、多井位划分 | 衡量稳定性 |

高发育区阈值建议使用以下方式之一，并在实验中固定：

1. 训练集裂缝密度的 top 20% 分位数；
2. 领域定义的固定密度阈值；
3. 验证集上确定阈值，测试集不再调整。

合成数据评价时建议同时报告：

1. 全图指标；
2. 排除训练井位置后的非井区域指标；
3. 高裂缝密度区域指标；
4. 断层附近/层位边界附近局部指标。

私有数据评价时建议报告：

1. 每次 leave-one-well-out 的指标；
2. 所有留出井的均值和标准差；
3. 按裂缝强度区间划分的误差；
4. 如样本允许，补充 leave-one-interval-out。

### 13.7 公开代理任务执行协议

公开代理任务不是主任务，但需要定义到可执行程度。

| 数据集 | 建议任务 | 输入 | 输出/真值 | 评价 |
|---|---|---|---|---|
| OpenFWI | 少标签二维结构场重建 | 地震/速度相关结构图 + 少量一维采样 | 二维速度或结构属性 | MAE、RMSE、SSIM |
| FaultSeg3D | 少标签断层图恢复 | 地震图 + 少量断层线/点标注 | 完整断层 mask | F1、IoU、PR-AUC |
| CRACKS | 弱标签置信度验证 | 地震图 + 低质量/低置信标注 | 专家标注 | F1、IoU、置信度-误差相关性 |
| Thebe | 真实地震结构泛化 | 地震图 + 少量标注 | 断层/结构标签 | F1、IoU、跨域性能 |
| F3/Penobscot | 多模态输入组织 | 地震、层位、井数据 | 地震相/结构辅助标签 | 输入构造、辅助验证 |

实施优先级建议：

1. 第一阶段只做 OpenFWI 或 FaultSeg3D 中的一个代理任务；
2. 若需要突出弱标签机制，再补 CRACKS；
3. Thebe、F3、Penobscot 可作为后续增强，不应阻塞主实验。

### 13.8 风险预案

| 风险 | 影响 | 预案 |
|---|---|---|
| UniMatch V2 改连续回归复杂 | 延误主模型实现 | 先用 U-Net/SegFormer masked regression 实现最小版本，再迁移到 UniMatch V2 |
| 合成数据被质疑规则过强 | 影响主实验说服力 | 增加 OOD 生成器、隐藏因子、公开代理任务和私有验证 |
| 公开代理数据处理成本高 | 延误实验进度 | 先保留为 P1/P2，不阻塞 E1-E3 和 E5 |
| 私有留一井提升不明显 | 影响真实应用验证 | 分析不同井/层段/裂缝强度区间，检查虚拟井控范围和结构条件质量 |
| 虚拟井控引入负迁移 | 影响方法主张 | 通过 E2 展示无约束虚拟井控风险，并突出置信度门控的必要性 |
| 基线适配不公平 | 审稿风险 | 统一输入、训练预算和随机种子，明确哪些基线是主任务基线，哪些是代理任务基线 |

### 13.9 实施顺序建议

建议按照以下顺序实施：

1. 实现自建合成数据生成器；
2. 实现 U-Net 或 SegFormer masked regression 最小基线；
3. 实现虚拟井控生成模块；
4. 完成 E1/E2/E3 的最小合成实验；
5. 接入 UniMatch V2 或半监督一致性训练；
6. 完成 E4 稀缺鲁棒实验；
7. 完成私有数据 leave-one-well-out 验证；
8. 根据时间补充 OpenFWI、FaultSeg3D 或 CRACKS 代理任务；
9. 整理主结果、消融结果、鲁棒性曲线和私有匿名指标。
