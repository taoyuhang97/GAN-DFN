## 3. 包内结构（决定解压落点）

压缩包的一级条目只有三项，全部是**相对项目根目录**的路径，不含任何绝对路径：


## 4. 压缩包放在哪里

压缩包本身放哪都行（现在就在 `<项目根目录>/delivery/` 下，也可以先拷到家目录或上一级目录）。
真正决定落点的是解压命令里的 `-C <项目根目录>`，不是压缩包的位置。

## 5. 解压命令

### 推荐：用 `-C` 指定项目根目录

```bash
tar -xzf GAN-DFN_交付_C方案_砂砾岩矿区v1+太古界quanqu1_20261016.tar.gz \
    -C /path/to/GAN-DFN
```

把 `/path/to/GAN-DFN` 换成对方机器上的项目根目录即可。

### 已经站在项目根目录里

```bash
cd /path/to/GAN-DFN
tar -xzf delivery/GAN-DFN_交付_C方案_砂砾岩矿区v1+太古界quanqu1_20261016.tar.gz
```

（不带 `-C` 时默认解压到当前目录，所以必须先 `cd` 到项目根目录。）

### Windows

方式一（推荐）：用 Git Bash，命令与上面完全一致。

方式二：用 7-Zip —— 右键压缩包 → `7-Zip` → `提取到指定位置…`，目标填**项目根目录**
（注意：**不要**点"提取到 xxx\"，那会多套一层同名文件夹）。

## 7. 注意事项

1. **不要双击解压**。macOS/Windows 双击默认会在"下载"里新建同名文件夹，
   落点就错了；请按第 5 节用 `-C` 指定，或解压后手动移动合并。
2. **中文路径**：包内是中文目录名，Windows 建议用新版 7-Zip 或 Git Bash；
   Linux/macOS 的 `tar` 原生支持。
3. **解压时提示"文件已存在"**属正常：包内只含本次交付件，
   若目标机器已有同名文件，覆盖的也是同一批成果，可以覆盖。
4. **磁盘空间**：解压需约 1.4 GB 可用空间。
5. **只读不改**：本包是"交付浏览版"，不含 Step1–6 的样本表与密度体 `.sgy`，
   **不能用于重算**，只用于查看 DFN、图件与统计表。
6. **不要把这个压缩包提交进 Git**：582 MB 超过 GitHub 单文件 100 MB 上限，
   push 会被拒绝；仓库 `.gitignore` 已排除 `delivery/`。

## 10. 成果口径提醒

1. **Z 约定**：正式文件 Z = |TWT|（ms，正值）；`dfn_display_zflip*` 是负 Z 镜像展示版，
   仅用于 ParaView 显示，不参与计算。
2. **P33 成像标定**（砂砾岩 Step9b）：以车页1导眼为基准的层段常数因子，属"点标定全区"，
   空间分布仍由 DFN 决定；太古界未做标定，其密度图为 DFN 相对体密度。
3. **地层口径**：砂砾岩 = 沙三段 / 沙四段；太古界 = 上部复合层（T4→T6）/ 太古界风化壳（T6→T7）。
4. **坐标**：X = Easting、Y = Northing（米）。
   砂砾岩矿区 X 556150–581650 / Y 4193975–4212275；太古界 X 658887–679500 / Y 4231662–4247987。
