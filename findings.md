# Findings

- Current `lowcoh_add` Step6B postprocess enhances all low-coherence regions equally, so horizontal stratigraphic black bands can be incorrectly converted into high-density DFN candidates.
- New implementation should compute a steep/vertical anomaly score from local low-coherence geometry and use it to gate additive compensation.
- `lowcoh_steep` improved low-coherence q20 hit rate versus `lowcoh_add` while removing most low-angle patches: q20 hit 53.11% -> 61.74%, dip<60 77.52% -> 0.23%.
- Current multiscale v1 should be treated as a runnable prototype, not final geology logic: Step7A is too sparse, Step7B medium patches are too large and visually dominant, and Step7C uses too little of the existing segmented fault surface information.
- The next implementation should not start by tuning Step7 only. Step6 must first produce separate small/background, medium/corridor, and large/fault evidence channels, otherwise Step7 cannot distinguish background fractures from seismic-scale discontinuities.
- Stage 0 rebalance QC passed: density SGY, trace mapping, source SGY, Coherence, AntTrack, CurvatureMax, and CurvaturePos align through `SourceXY`/`source_trace_idx`; attribute sample ranges fully cover the density range 2240-3240 ms.
- Existing segmented fault patches can be reused for the Cheye1 demo large-scale fault path: 79 patches intersect demo+500m in XY/T, sampled VTP files were readable, and 66/79 patches match `FaultStick-GeoEast.dat` by fault name, XY window, and time margin. GeoEast should remain the original fault overlay/QC source.
- Step6A rebalance creates a broader small-scale sampling pool than the previous sparse Step7A path: 6.02% candidate voxels and 2.51% core voxels. This should help restore background fractures, but Step7A must keep patch size small so the background does not dominate visuals.
- Step6B rebalance fixed the previous giant medium-component issue: retained medium candidates are 2.44% of voxels across 211 components, and the largest component is only 1.53% of retained voxels. Step7B should preserve these component IDs and local orientations rather than recomputing a single abstract centerline.
- Step6C rebalance currently has no inferred large low-coherence faults. With relaxed thresholds, candidates still failed the steep/vertical-continuity checks, so large-scale evidence is only the 26 original segmented fault patches. This is a conservative result: do not force horizontal or low-dip coherence anomalies into large faults. Missing smaller faults should mainly be handled by Step6B medium corridors unless further geologic QC proves a low-coherence candidate is a true fault.
- Step6D scale labels are well separated for the next Step7 pass: small 5.55%, medium 2.36%, large 2.64%. Overlaps exist but are resolved by large > medium > small priority.
- Step7A rebalance is materially better than the old sparse background path: 3000 patches, median length 27.67 m, median height 7.69 ms. Most orientations came from local density PCA, so the background is no longer a thin template-like sprinkle.
- Step7B rebalance now behaves like a corridor model instead of a single giant blob: 709 patches across 60 bands, median length 170 m, median height 30 ms, and median dip about 49.9 deg. The medium-scale result is still somewhat large in footprint, but the geometry is much more geologically legible than the old version.
- Step7C rebalance successfully switched to segmented fault patch panels: 52 large patches total, 26 original fault panels plus 26 damage-zone patches. No inferred low-coherence large faults survived the steep/vertical QC, which is a conservative and defensible outcome for the current demo.
- Step8 rebalance produced a valid corrected DFN and well-control patches, but the legacy `far_field_preserved` QC still fails because roughly 24.9% of the initial patches were changed or added. This is a QC-policy issue, not a geometry export failure, and Step9 still ran successfully from the corrected VTK.
- Step9 rebalance outputs are usable: the two overlay figures show the DFN, coherence, Step3 imaging fracture labels, and the current fault-trace overlay path. The current original fault trace still does not intersect the XZ/YZ sections with enough local points to show visible segments, so the summary correctly reports zero visible fault trace segments.
- Step7C should not use segmented fault summary bbox + strike/dip to reconstruct original faults. The faithful path is to reuse the old fault postfusion tools: `run_build_fault_surface_fragments()` for raw fault-core surface fragments and `run_build_regional_fault_panels()` only for broader panel/influence geometry. This avoids changing the original unit fault surface orientation during Step7C.
- Step7C low-coherence inferred large faults should not be exported as one rectangle per Step6C component. The better representation is a panel group within each component, split along the component's main direction with slight overlap. In the current v3 preview this produces 35 panels from 12 inferred components, making the inferred large-fault candidate look like a continuous断裂带 rather than isolated giant blocks.
- Step6C fixed XY/T tile splitting is not geologically valid for inferred large faults. The revised `surface_ransac` mode can produce non-rectangular continuous surface candidates, but broad surfaces spanning most of the 3000m demo area should be rejected as regional low-coherence trends unless a geologist confirms them. The conservative `candidate_cheye1_step6c_large_surface_ransac_v4_strict` result keeps only one local steep inferred surface, which is more defensible than forcing many new large faults from low-coherence evidence.
- Step9 strict polygon-plane intersection explains the sparse section figures: current DFN has 7704 patches, but the original section view only plotted 213 XZ and 193 YZ true intersections because nearby patches that do not physically cross the exact section plane were omitted. The new small-scale projection mode restores a half-width-style display only for `FractureScale=small`; medium and large features remain true intersections to avoid moving structural-scale objects artificially onto the section.
- The latest medium-scale mismatch with vertical low-coherence is primarily upstream of Step9. Step6B is AntTrack-led (`AntTrackScore * (...)`), so strong vertical low-coherence anomalies with weak AntTrack support are suppressed before Step7B. In the 0.65 vertical low-coherence QC, uncovered components had mean AntTrack score 0.176 versus 0.370 for components with >=10% Step6B overlap. Step7B then further drops coverage because it selects only the top score-mass medium components; current v2 lineage uses Step7B rebalance v1 where only 58/211 Step6B components received patches. Low-dip medium patches are also still present: about 29.8% of Step7B medium patches have dip <30 degrees and 45.7% have dip <45 degrees.
- Step6B should not simply convert all low-coherence voxels into medium corridors. The safer change is a separate low-coherence branch that still passes vertical extent, dip, linearity, and layer-like rejection in `build_medium_components()`. This keeps vertical discontinuities available while continuing to reject horizontal stratigraphic interfaces.
- The first `candidate_cheye1_step6b_medium_lowcoh_vertical_v1` preview proves the low-coherence branch is effective upstream: exact steep lowcoh voxel overlap increased from 17.07% to 68.71%. Step7B center hits also improved, but the absolute exact-hit fraction is still 7.76%, so the full Step7D/Step8/Step9 chain may still need fusion and section-display tuning before the visual match becomes obvious.
- The final unified Step7B covers 95/99 layer-clipped components, but this component-level coverage does not replace the 7.76% exact steep-lowcoh center-hit metric. Per-trace-horizon Step9 figures should decide whether further in-component sampling changes are necessary.
- Step6 positioning QC supports using the current density as a small-scale background for the demo, but true leave-one-well retraining validation has not been run and remains required before external cross-well generalization claims.
- `smallwell_event_v1` is the 2026-07-23 checkpoint Step8: 729 raw Step4 points aggregate to 104 events; 99 Step4 events plus 60 Step3 imaging controls produce 8,537 final patches, with all 159 well-control patches marked small and a 1.89% changed/added fraction.
- Original fault interpretation is loaded for Step9, but the current Cheye1 curved XZ/YZ sections have zero visible original-fault segments because they do not intersect enough original fault geometry; this is not a missing-input condition.
- The reusable horizon trace table contains 2,990,065 finite T4-T7 records. Active Step9 code uses it, but only the mine-wide seismic-amplitude preview has completed the new display path so far.
