# 太古界 Step4 目标层位与地震覆盖问题记录

更新时间：2026-09-01

## 1. 问题结论

当前 Step4 已经对测井样本做了目标地层筛选，但它解决的只是“样本是否位于 Top–Mid 或 Mid–Base 目标层段”，没有解决“样本是否有当前 OBN/地震属性体覆盖”。因此，Step4 输出中出现部分矿区外井的预测结果并不代表目标层位筛选失效。

Step4 当前实际筛选为：

```python
well_rows = well_rows[well_rows.StrataName.isin(TARGET_STRATA)].copy()
```

其中目标层为：

- `上部复合层`
- `太古界风化壳`

这意味着 Step4 的有效预测结果原则上位于层位定义的目标层内，但没有 OBN 覆盖约束。

## 2. 当前各层数据职责

### Step1/Step2

- Step1 使用井口坐标与 Top/Mid/Base 层位网格做最近点匹配，当前允许最大层位匹配距离约 100 m。
- Step2 对普通井按逐行 X/Y 查询 Top/Mid/Base 并分类；对成像井按 TVD 解释区间和边界分类。
- Step2 将样本限定为两个目标层，并保留 MD、TVD、X、Y、TIME。

### Step4

- Step4 读取 Step2 已分类的目标层样本；训练和预测均按 `StrataName` 处理。
- Step4 预测依赖 GR/RD/RS 测井特征，不依赖 OBN 振幅、相干、蚂蚁或曲率覆盖。
- 因此只要井有有效层位/时深和测井曲线，即使位于当前 OBN 地震覆盖范围外，也可以产生井上裂缝预测。

### Step5/Step6A

- Step5 需要将 Step4 预测点转换为地震-井联合样本，因此还必须检查 OBN 最近道距离和四属性有效性。
- Step6A 的三维模型只能使用具有可靠地震属性的样本；不能把矿区外井的 Step4 预测直接当成有地震支持的训练样本。

## 4. 风险与影响

- 如果 Step5 直接读取全部 Step4 预测，可能把没有地震支持的井段误当作地震-井联合训练样本。
- 如果用最近的 OBN 道代替距离数公里的井点，会产生严重的空间错配。
- 405 井口、井轨迹和成像井真实时深尚未最终核验，涉及 405 的 TIME 对齐和井控结论仍属于暂定工程结果。
- Step4 输出中的 `PredictionValid=1` 只表示 Step4 测井预测有效，不表示 OBN/四属性采样有效。

## 5. 后续处理原则

不建议为了适配 Step5 而修改 Step4 的目标层位筛选；应在 Step5 增加独立的地震覆盖 QC 和训练资格判断。

每个 Step4 预测点应增加或计算：

```text
NearestOBNTrace
NearestTraceDistM
InOBNCoverage
CoherenceValid
AntTrackValid
CurvatureMaxValid
AttributeValidCount
TrainingEligibility
```

最终分为：

1. 目标层内且地震属性有效：可进入 Step5/Step6A 联合训练；
2. 目标层内但地震覆盖外：保留 Step4 井上预测和独立审计，不进入当前 OBN 三维训练；
3. 层位无效或不在目标层：不应进入 Step4 正式预测。

本记录用于说明 Step4 与 Step5 的职责边界，不改变既有 Step4 输出。
