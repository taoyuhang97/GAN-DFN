更新时间：2026-08-27

## 1. 文档目的

本文用于记录太古界地区当前项目的整体技术理解、已完成链路、与砂砾岩正式主线的对应关系，以及后续工作的边界。本文不是某一步的运行说明，也不替代《太古界Step1-4交接文档_20260822.md》和《太古界Step5-9交接文档_20260822.md》中的具体数据清单、输出合同和验收数字。

后续实现应以太古界自身的数据合同为准，以 `优化阶段二/正式主线` 中砂砾岩方法作为架构和算法参考，不得直接混用砂砾岩的井、层位、坐标、时间轴、配置、输出或历史结果。

## 2. 项目总体目标

太古界项目的目标是：以成像测井解释为监督，结合常规测井预测无成像井裂缝分布，再利用 Coherence、AntTrack、CurvatureMax 三种地震属性构造三维离散裂缝网络（DFN），通过成像井进行井控校正，并沿代表性井轨迹生成可解释的剖面和后续密度量化结果。

项目最终应形成一条可追溯、可复现、可分尺度验收的流程：

```text
层位/时深/TVD 合同
→ 常规井与成像井样本底板
→ 成像监督标签
→ GR/RD/RS 常规测井裂缝预测
→ 虚拟井与统一训练样本
→ Step6A-D 多尺度地震证据体
→ Step7A-D 分尺度 DFN
→ Step8 井控校正
→ Step9 多背景剖面与验收
→ 密度量化和展示交付
```

## 3. 太古界自身的数据与语义边界

### 3.1 井、深度和时间

- 常规测井 LAS 的深度是 MD（沿井测深），不是 TVD。
- 成像解释段上下界、密度和点位深度的正式语义是 TVD。
- 井斜、轨迹和时深关系用于将 MD/TVD 转换到 X/Y/TIME 地震坐标。
- 成像井目前部分缺少本井真实时深，借用最近常规井时深仅用于 TIME 标注；相关样本必须保留 `temporary_neighbor_time_depth=1` 和置信度，不能静默视为真实时深。
- 若后续补齐真实时深，受影响的 Step2 及其下游步骤必须按依赖关系重建。

### 3.2 层位和窗口

太古界当前使用三界面逐道层位合同：上部复合层顶 Top、太古界顶 Mid、风化壳底 Base。主目标窗由 Top 至 Base 构成，并按界面划分地层。Base 以下另有最多 50 ms 的下伏延伸分析窗，独立标记为 `WindowCode=2`。

延伸窗不是正式三界面内部地层，也不能覆盖、修改或重命名三界面合同。它没有勘区内真实监督，密度预测只能使用风化壳模型外推，结果应标记为低置信度并与主窗分开统计、展示和审计。

### 3.3 属性数据使用口径

- Demo 区为 5 km × 5 km，最终范围为 X[660500,665500]、Y[4238400,4243400]，按 OBN 网格对齐为 401×401 道。
- 基础密度体时间轴为 2 ms，范围 2248–3446 ms。
- 正式 DFN 主流程不再使用 OBN 原始地震振幅。OBN 网格与属性体网格不一致，OBN 实际道数为 2,002,838，而三种属性体均为 2,156,550 道；继续绑定振幅会产生网格错配和无意义缺道筛选。OBN 仅保留为独立空间覆盖 QC 和对比资料。
- 正式属性输入为 `Coherence`、`AntTrack`、`CurvatureMax` 三种属性。属性体完整规则网格作为 Step5–Step9 的空间主网格，曲率体道序定义统一 `TraceIdx`。
- 2026-08-26 起，蚂蚁体（AntTracking）、本征相干（Eigenstructure Coherence）和最大正曲率（Most Positive Curvature）已可用。属性体文件时间语义为“文件索引 + 1800 ms”，采样时需要按 1 ms 属性轴插值到目标时间轴。
- 蚂蚁体约 55% 为 `-1` 空值；`<=-0.99` 必须按无效处理，不能作为正常低值参与模型或连续性计算。

## 4. 已完成工作

### 4.1 Step1–Step4：太古界上游链路

Step1–Step4 已完成并验收通过：

- Step1 建立层位、时深和成像 TVD 合同；
- Step2 建立常规/成像测井的 MD/TVD/轨迹/TIME 段底板；

- Step4 使用 GR/RD/RS 两阶段模型生成全井合并裂缝密度预测和裂缝点。

Step4 的正式衔接输出是按 `WellName+TVD` 唯一的合并密度预测表、裂缝点表及相关 manifest；这些结果是 Step5 的正式上游输入。

### 4.2 Step5–Step9：当前小尺度 v2 闭环

当前 v2 已完成并逐步验收通过：

- Step5：使用常规井和成像井构造 5×5 虚拟井；虚拟 TIME 按局部层位重算；已加入振幅连续性评分、低连续性门控、密度/置信度衰减和虚拟样本权重约束。
- Step6A：训练两阶段密度模型，生成 2 ms demo 区连续裂缝密度体；上部复合层和风化壳独立训练、独立报告。
- Step7A：按地层分层加权采样生成小尺度裂缝片，并结合 405 成像解释方向族和局部 PCA 估计方向。
- Step8：使用埕北古斜405 成像控制点进行替换、新增和井周密度增强；弱控制单独记录，未匹配时不强行调整。
- Step9：沿埕北古斜405 LAS DEV 积分轨迹生成弯曲 XZ/YZ 剖面，叠加振幅、密度体、成像标签、井轨迹和裂缝面与剖面的交线。

当前成果证明太古界已经具备小尺度基础闭环，但尚未达到砂砾岩正式主线的多属性、分尺度 DFN 完整能力。

## 5. 与砂砾岩正式主线的关系

砂砾岩 `优化阶段二/正式主线` 已验证的主要方法和工程约束，是太古界后续完善的参考基线：

- 先建立逐道层位合同，再进行井样本、地震采样和 DFN 构造；
- 真实井、成像监督、虚拟井、统一训练样本分层组织；
- `PresenceLabel` 与仅正样本定义的 `DensityLabel` 双标签；
- 两阶段密度模型：存在概率 × 正样本条件密度；
- 按源井分组验证，禁止真实井和其虚拟子井跨折泄漏；
- 虚拟井按局部层位重算 TIME，并以属性连续性控制迁移可信度；
- 小、中、大尺度裂缝分别在 Step6A-D 和 Step7A-D 中建模、几何化和融合；
- 原始断层几何与预测裂缝片在统一 VTK 中显式分组并全程传递；
- Step8 仅按规则修改允许修改的小尺度片，中、大尺度和原始断层保持地质主体；
- Step9 使用真实 X/Y/TWT 曲面采样，显示裂缝面-剖面交线，并保留综合图、单尺度诊断图和 QC 摘要；
- 每步均有独立输出目录、配置、日志、验收摘要和可追溯审计。

这些方法只能作为太古界的迁移框架。太古界的层位名称、深度语义、临时时深处理、属性空值规则、断层输入形式和窗口定义必须保持独立。

## 6. 后续完善的总体方向

后续工作的目标是将当前“振幅驱动的小尺度闭环”逐步提升为“太古界专用的多属性、多尺度、可审计 DFN 主线”：

1. 先完成属性体接入和 Step5/Step6A 合同升级，确认多属性采样、配准和跨井验证可靠。
2. 再实现 Step6B/C/D 与 Step7A/B/C/D，将蚂蚁体中尺度证据、断层/低相干大尺度证据和损伤带增强纳入统一流程。
3. 在多尺度流程稳定后，完善 Step8/Step9 的分尺度井控、单尺度诊断、主窗/延伸窗区分和展示交付。
4. 并行推进 405 井口、井轨迹和成像井真实时深核验；如坐标或时深变化，按依赖关系重建受影响链路。
5. 最后再进行模型校准、成像密度量化、全区扩展和正式版本冻结。

## 7. 当前明确的限制

- 风化壳在勘区内缺少成像强监督，当前主要依赖弱监督。
- Step4/Step6 当前指标属于基线，不能作强地质解释。
- 成像井临时时深会影响虚拟井 TIME、地震属性采样和井控空间匹配。
- Base 下伏 50 ms 没有真实监督，必须低置信度单独处理。
- 405 井口坐标尚未用 `CBGX405.prn` 与 LAS XE/YN 完成最终核验。
- 属性体满格而 OBN 有缺道，最近道采样可能产生空值、替代或插值误差。
- 太古界断层当前以线段解释为主，不能直接假设其已具备砂砾岩流程所需的三角断层面。

## 8. P0 多属性接入与基础密度升级规划

### 8.0 当前新增风险记录（2026-08-28）

- 405 井口坐标、井轨迹与成像井真实时深目前仍未完成最终核验；现有流程中部分成像井 TIME 仍可能来自邻井临时时深。
- 在该核验完成前，属性采样 smoke/QC 和 P0 试运行只能作为工程验证，不能把井控空间匹配、成像标签 TIME 对齐或模型指标解释为最终地质结论。
- 若核验后 405 井口、轨迹或真实时深发生变化，至少需要重建受影响的 Step2/Step3/Step4，并重新运行 Step5 以后全部依赖步骤；旧 v2 和当前 P0 试运行结果均不得覆盖。

### 8.1 P0 的目标和范围

P0 的目标是把当前太古界“振幅驱动的小尺度闭环”升级为“多属性驱动的小尺度基础闭环”：正确接入蚂蚁体、本征相干和最大正曲率，升级虚拟井连续性判断、统一训练样本和 Step6A 基础密度预测，并重跑小尺度裂缝片、井控和剖面。

P0 暂不实现中尺度/大尺度裂缝的完整 Step6B/C/D、Step7B/C/D，也不在本阶段修改太古界 Step1–Step4 的 MD/TVD/TIME 和成像标签语义。P0 的所有新结果必须使用独立版本目录，不覆盖当前已验收的 `taigu_step5_v1`、`taigu_step6a_v1` 及其下游结果。

### 8.2 砂砾岩方法的属性口径

砂砾岩正式主线实际使用的是“三种后处理属性 + 原始地震振幅”四类地震信息：

```text
Coherence + AntTrack + CurvatureMax + SeisAmp
```

不同步骤的使用方式不同，不能把所有权重混成一套：

- Step5 虚拟井连续性是显式加权的属性相似度。初始权重参考砂砾岩正式配置：`CurvatureMax=0.65`、`Coherence=0.15`、`AntTrack=0.15`、`SeisAmp=0.05`。这组权重只表示“源井标签能否可信地转移到虚拟位置”，不是密度模型的固定属性贡献比例。
- Step6 两阶段密度模型把四种地震信息都作为输入特征，由模型在训练中学习非线性作用，不手工规定曲率占 65% 或振幅占多少。后续通过按源井留井验证、特征重要性和属性消融实验评价各属性贡献。
- 砂砾岩 Step6A 另有“基础密度 + 普通曲率”的小尺度背景融合，当前正式参考权重为各 `0.50`。太古界不能未经属性质量检查直接照搬该比例，应在 P0 验证曲率质量后决定是否采用。
- `SeisAmp` 有必要保留：它是覆盖最基础、最完整的原始观测，可提供局部反射和波形变化信息，也是虚拟井的弱辅助特征和 Step9 的主要背景。它不是主导裂缝属性，但不能未经消融验证直接删除。

### 8.3 P0-1：属性数据和采样合同

新增太古界专用属性采样层，负责在真实井点、虚拟井点和 demo 区地震道上采样 `SeisAmp`、`Coherence`、`AntTrack`、`CurvatureMax`。采样按 X/Y 最近道定位，属性体按 1 ms 时间轴线性插值到 Step6A 的 2 ms 轴。属性体时间语义固定为“文件索引 + 1800 ms”。

蚂蚁体 `<=-0.99` 视为无效，不能填成 0，也不能作为正常低值参与连续性或训练。OBN 缺道、属性体满格、最近道距离和各属性空值状态均须保留审计字段。

采样阶段先做少量井/少量道 smoke test，再做 401×401 demo 区全量采样。至少输出属性覆盖率、层位附近有效率、蚂蚁体有效率、最近道距离、时间配准和随机抽查结果；采样合同和 QC 必须有独立 `summary.json`，状态为 `pass` 才能进入 Step5。

### 8.4 P0-2：虚拟井四属性连续性

保留当前太古界的 `5×5` 邻域、虚拟 X/Y、局部层位重算 `VirtualTIME`、时间偏移门控、距离衰减、低置信度剔除和 `PointConfidence/25` 权重。改造重点是把原来的振幅连续性升级为四属性连续性。

每个属性先按稳健尺度标准化，再计算源点与虚拟点的相似度。有效属性才参与计算；无效属性不得当作 0。建议首版要求至少 2 个属性有效，按实际有效属性重新归一化权重，并记录 `AttributeValidCount`。关键属性缺失或总体连续性不足的样本进入审计，不进入正式训练。

通过门控的正样本使用：

```text
虚拟 DensityLabel = 源 DensityLabel × AttributeContinuity
```

`PresenceLabel` 继续继承源井；负样本的 `DensityLabel` 必须为空，不能用 0 伪造连续密度观测。

### 8.5 P0-3：统一训练样本合同

统一样本需要同时包含真实井和通过门控的虚拟井，并保留 `SourceKind`、`SourceWellName`、`TrackWellName`、`LayerCode`、`WindowCode`、双标签、`PointConfidence`、`SampleWeight`、四种地震属性及属性有效性字段。

成像井的 `temporary_neighbor_time_depth` 必须保留；Base 以下 50 ms 样本继续使用 `WindowCode=2` 独立标记。延伸窗可以用于模型预测或外推，但没有真实监督，不能混入主窗监督训练。统一表验收需检查源样本可回指、正负标签语义、虚拟权重上限、属性有效状态和主窗/延伸窗分离。

### 8.6 P0-4：Step6A 多属性两阶段密度模型

模型仍按地层独立训练：第一阶段预测裂缝存在概率，第二阶段只对正样本预测条件密度，最终为：

```text
PredDensity = PresenceProbability × PositiveConditionalDensity
```

输入包含振幅及其上下文、`Coherence`、`AntTrack`、`CurvatureMax` 和层位几何特征。四种属性在模型中均作为可学习特征，不预设固定贡献比例。`WindowCode`、属性有效性和临时时深标记优先用于 QC/分层统计；是否直接作为模型特征，须由验证结果决定，避免模型学习数据来源差异而不是裂缝规律。

训练必须按 `SourceWellName` 分组留井验证，真实井及其全部虚拟子井进入同一折。上部复合层、风化壳分别报告 AUC、AP、密度 MAE/R²、预测覆盖率和属性有效率。Base 下伏延伸窗不参与训练，使用风化壳模型外推并标低置信度。

必须建立当前振幅版本与 P0 多属性版本的可复现对比，包括指标、各井预测分布、成像密度参照、主窗/延伸窗统计，以及去掉某一属性后的消融结果。

### 8.7 P0-5：预测体、小尺度裂缝片和下游重跑

新的 Step6A 预测体仍为 demo 区 `160,801` 道、`2248–3446 ms`、2 ms 采样，并独立输出模型、SGY、trace mapping、`window_code`、属性有效性、训练/预测/验收 summary。需检查道头、X/Y、时间轴、层窗、密度上限和 OBN 缺道映射。

Step6A 改动后，必须使用新密度体重跑 Step7A 小尺度裂缝片、Step8 井控和 Step9 弯曲剖面。Step7A 继续采用分层概率采样和 405 成像方向先验；Step8 仍只校正小尺度片；Step9 需要区分主窗和 Base 下伏 50 ms 延伸窗。

P0 的最低重跑链路为：

```text
属性采样 → Step5 虚拟井 → 统一样本 → Step6A 训练/预测
→ Step7A → Step8 → Step9 → 全链验收和前后版本对比
```

若同时修改了 Step1–Step4 的标签、井位、时深或 Step4 合并预测，则必须从受影响的最上游步骤重建，不能只重跑 P0 下游。

### 8.8 P0 完成判据

P0 只有在以下条件同时满足时才算完成：

1. 四类地震信息采样正确，属性时间/空间配准通过；
2. 蚂蚁体无效值处理正确，覆盖率和空值有审计；
3. 虚拟井四属性连续性、置信度和剔除原因可追溯；
4. 双标签、样本权重、临时时深和延伸窗合同保持正确；
5. Step6A 按井分组验证，无真实井/虚拟井泄漏；
6. 完成振幅基线与多属性版本、以及属性消融对比；
7. 新 Step6A、Step7A、Step8、Step9 输出均使用独立版本并 `status=pass`；
8. 旧 v2 结果未被覆盖，文档记录了版本、参数、QC 和重跑范围。
