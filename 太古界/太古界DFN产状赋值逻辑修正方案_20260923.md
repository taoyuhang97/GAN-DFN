### 1.1 与 405 的分布差异（azi2 版本，井周 500 m、目标层内 1116 片 vs 405 真实裂缝 301 条）

### 1.2 各成像井之间本来就不是同一套体系（决定性证据）

| 井/组 | 点数 | 倾角中位 | ≥75° 占比 | 倾向方位环形均值 |
| --- | --- | --- | --- | --- |
| 埕北310 | 34 | 47.0° | 0% | 190.8° |
| 埕北313_g001 | 491 | 61.6° | 13% | 190.4° |
| 埕北313_g002 | 24 | 50.0° | 0% | 152.0° |

| 桩斜169 | 278 | 66.5° | 30% | 190.6° |
| 埕北816（风化壳） | 45 | 56.8° | — | 341.2° |

* 310 / 313_g001 / 169 三口井的倾向方位**几乎完全相同**（190.8° / 190.4° / 190.6°，彼此差 0.2–0.4°）；
* **405 是 339.3°，与上面三井差约 149°**，方向几乎相反；816（341.2°）与 405 同派；
* 倾角也分派：310 一条 ≥75° 的缝都没有，405 有 53%。

**结论：不存在"区域的统一产状分布"。** 现在 7A 的做法是"按层把各井点按井等权混合后再 KMeans 求家族均值"，
从原理上就会把两派搅在一起——这正是 DFN 多出 170°/230° 反向峰、且陡倾尾巴消失的原因。

### 1.3 第二个原因：局部地震几何被"直接采用"

azi1 的 7A 片按来源拆分：

| 来源 | 占比 | 倾角中位 | <40° 占比 |
| --- | --- | --- | --- |
| `multiwell_family`（按层平均的家族） | 65% | 61.0° | 0% |
| `local_gradient_ridge`（地震体局部几何） | **21%** | **31.0°** | **81%** |
| 混合 | 14% | 50.1° | 12% |

即：**21% 的片直接采用了明显偏浅的局部几何产状**，而且没有任何"与区域统计是否一致"的门控。

## 4. 新的产状赋值算法

### 4.1 总流程

对每一个被接受的小尺度片（中心 `(x, y)`，层 `layer`）：

```
1) 井权重      w_i(x,y)   = 距离核(该层可用井 i 的位置)
2) 抽井        i*         = 按 w 采样（空间相关，见 4.3）
3) 抽产状      (D, δ)     = 从井 i* 在该层的经验点里采样 + 核抖动
4) 局部几何    (D, δ)     ← β 门控：仅当走向一致时小幅融合倾角
5) 写出        DipAzimuthDeg = D,  AzimuthDeg = (D-90)%180,  DipDeg = δ
```

### 4.2 井权重（D2）

对每口可用井 i（该层配置在 `imaging_wells_by_layer` 内的井），井位 `(x_i, y_i)`：

```
d_i = hypot(x - x_i, y - y_i)
g_i = exp(-(d_i / L)^2)          # 高斯核，保证处处 C¹ 连续
w_i = g_i / Σ_j g_j              # 归一化
剔除 w_i < well_weight_min_share 的井后重新归一化   # 默认 0.02
```

* 用**高斯核而不是硬性"最近 K 口井"**：`K 近邻`的硬截断会在 K 边界处产生权重跳变，
  而高斯核在数学上处处光滑，实际效果等价于"只受最近 2–4 口井支配"。
* 参数 `L = well_weight_scale_m`（默认见 §5.3 标定表）。

### 4.3 空间相关抽井（保证连续性，D2 的落地关键）

逐片独立抽井会让相邻片随机来自不同井，看起来仍然"乱"。因此：

```
预生成一张 coarse grid（网格步长 = well_assignment_coherence_m，默认 800 m）的均匀随机数场，
并做高斯平滑（σ ≈ 1 个格）→ 得到平滑随机场 u(x, y) ∈ [0,1)（双线性插值取值）
对每个片：用 u(x, y) 作为分位点，在累积权重上反查井号 i*
```

效果：相邻片倾向于抽到同一口井，形成**空间连贯的产状域**，而在域边界处权重是渐变的。
这是把"取最近几口井加权"落到"DFN 连续"上的必要一步；`well_assignment_coherence_m` 越大域越整块。

### 4.4 从选中井采样（D1）

井 i 在层 `layer` 的经验点集 `P_i = {(D_k, δ_k)}`（**全部成像点**，符合 D1）：

```
采样一个点 (D_k, δ_k)（等概率）
D = (D_k + ε_D) mod 360,  ε_D ~ N(0, azimuth_jitter_std_deg)      # 默认 8°
δ = clip(δ_k + ε_δ, dip_min_deg, dip_max_deg),  ε_δ ~ N(0, dip_jitter_std_deg)   # 默认 5°
```

* 直接**重采样经验分布**（而不是取家族均值），因此多峰、陡倾尾巴、井间差异全部保留；
* 抖动带宽远小于井间差异（149°），不会破坏分布形状；
* 越界的倾角裁剪到 `[dip_min_deg, dip_max_deg]`（默认 `[5, 89]`）。

### 4.5 局部几何的 β 门控（D3）

局部几何给出 `(D_local, δ_local)`（来自 7A 现有的 `local_gradient_ridge_orientation`）与其质量 `q`：

```
S_samp  = (D - 90) % 180          # 统计采样值的走向
S_local = (D_local - 90) % 180    # 局部几何的走向
ΔS = 走向夹角(S_samp, S_local)     # [0, 90]

if ΔS <= local_geometry_strike_tolerance_deg (默认 30°) and q >= local_geometry_min_quality:
    β = local_geometry_dip_blend_max (默认 0.30) * q          # 权重上限 0.30
    δ = (1 - β) * δ + β * δ_local
    # 一并把方位向局部值做同样幅度的小幅融合（可选，默认开）
    D = 轴向融合(D, D_local, β)
    LocalGeometryUsed = 1
else:
    LocalGeometryUsed = 0        # 完全忽略局部几何
```

**注意比较的是"走向"（轴向、0–180），不是"倾向方位"**：平面法向的正负本身是任意的，
用走向比较才稳健。

**必须删除的旧逻辑**：现在"`quality >= local_high_quality` 时直接采用局部产状（占 21%、倾角中位 31°）"，
以及"按层等权混合的多井家族 KMeans + 家族均值"。二者都要被 §4.2–4.5 取代。

### 4.6 中尺度不动（D4）

7B/7C 保持现状（蚂蚁体／断层面几何来源）。**但要在 QC 里度量**小尺度与中尺度在同一位置的产状差异，
作为"是否需要在下一轮统一"的依据（本轮只测不改）。

### 7.3 副作用核查（结论：影响可控，但要在图上预期）

片的水平投影宽度按 Step8 顶点公式 `水平半宽 = (HeightTimeMs/2 × 2) / tan(倾角)` 计算：

| 倾角 | 30° | 45° | 60° | **76°** | 85° |
| --- | --- | --- | --- | --- | --- |
| 水平半宽 | 60.6 m | 35.0 m | 20.2 m | **8.7 m** | 3.1 m |

* 倾角整体从 ~59° 提到 ~76° 后，片的**水平投影宽度约减半**；`LengthM × HeightTimeMs`
  （即 `PatchAreaM2` 与密度口径）**不变**，因此 Step7D/Step8 的密度与尺寸校验不受影响。
* 用 Step9 geometry 模式的实际判据（`剖面到片中心的垂距 ≤ 片的法向半宽`）复算 405 井周小尺度片：
  XZ 的片中位法向半宽 10.8 m → 11.7 m，YZ 25.0 m → 22.7 m，**判为"剖面真的切到这片"的片数变化在个位数**，
  不改变图形的整体构成（绝大多数片本来就是"井周投影"）。
* 真正会明显变化的是**线的倾角**：XZ 剖面上 DFN 线的中位会从 19.4° 抬到 ~50°，
  YZ 从 57.8° 抬到 ~74°——**这正是要修的东西**。

### 7.4 核对结论

1. 新逻辑**只改变 `DipAzimuthDeg` / `DipDeg` 的取值来源**，字段语义与取值范围不变 → **Step9 无需任何改动**。
2. Step9 的成像粉线与 DFN 迹线**用的是同一物理量与同一画法**（已验证到 1e-6°）→ 方案不会引入新的口径歧义。
3. 方案目标（§6 G2–G4）在数学上可达成；图上的可见变化是"XZ 线变陡"，属预期。

### 10.4 实测发现并修正的一处方案问题（重要）

方案 §6 原定的 **G5 用"窗内平均产状的逐点跳变"**，实测**不成立**：

* 405 的倾向方位本身分布很宽（环形离散度 88°、近乎均匀/双峰）；
* 对这类分布求"窗内平均方位"极不稳定——实测相邻两窗（各 117、129 片，离散度 120°/143°）
  的平均方位从 152° 跳到 6°，**146° 的"跳变"纯属抽样假象**，不是真实的井边界突变。

因此 G5 已改为**分布级 + 权重场级**两条判据（见 10.3），并保留该说明。
**这不是数据或算法的问题，是原定验收指标选错了统计量。**
