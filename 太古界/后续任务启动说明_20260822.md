# 新对话启动说明：太古界小尺度裂缝 demo 区预测与剖面生成

更新时间：2026-08-22

`太古界/太古界Step1-4交接文档_20260822.md` 与 `太古界/数据使用说明.md`。

## 1. 背景

项目整体：以成像测井解释为监督，结合常规测井（GR/RD/RS）预测无成像井裂缝分布；
再以地震数据构造 DFN 并做井控校正，最后出沿井剖面。

太古界 Step1–Step4 已完成并验收（代码在 `太古界/`，commit `9ef45a9`）：

- Step1 层位/时深/TVD 合同（25 常规井 + 8 成像井）；
- Step2 常规测井 MD/TVD 段底板（17 井可用，逐行 X/Y/TVD/TIME/GR/RD/RS）；
- Step3 成像监督组（8 组 / 6 井，TVD 域标签）；
- Step4 GR/RD/RS 两专家裂缝预测（17 井合并密度曲线 + 裂缝点）。

本任务：**参考砂砾岩 Step5–Step9，以原始地震振幅（OBN）为基础，实现小尺度裂缝的
demo 区预测（密度体 → 裂缝片）与剖面生成**。

## 2. 已定参数（2026-08-22 确认）

1. demo 区：**5 km × 5 km**（以埕北310 等井区为中心定义 X/Y 边界，对齐 OBN 道头网格）；
2. 剖面井：**埕北310**（XZ/YZ，振幅背景 + 密度/裂缝片/成像标签叠加）；
3. 密度体时间轴：**2 ms**；
4. 虚拟井：**常规井 + 成像井都纳入**；成像井 TIME 为借用值，样本必须标记
   `temporary_neighbor_time_depth` 与置信度，不得静默当作真实时深；
5. 下伏 **50 ms 延伸窗**：本次起纳入逐道层位合同与预测，独立标记；
6. 输出优先级：**密度体 → 裂缝片 → 剖面**。

## 5. 实现框架（建议顺序）

1. **common**：三界面逐道层位合同（主窗 + 下伏 50 ms 延伸窗，独立标记）、
   OBN 道映射（trace_header_xy ↔ TraceIdx）、振幅体按道流式读取与采样工具；
2. **Step5（太古界）**：虚拟井构造（常规井 + 成像井，TVD 域、标记借用 TIME 与置信度）
   + 统一训练样本（Step4 合并预测为弱监督、Step3 组为强监督，振幅特征）；
3. **Step6A（太古界）**：两阶段模型（存在性 + 条件密度）训练 + demo 区 2 ms
   小尺度密度体预测（逐道主窗与延伸窗，分块流式写 SGY）；
4. **Step7A（太古界）**：小尺度裂缝片采样（密度分位数 + 局部 PCA 方位），输出 CSV/VTK；
5. **Step9（太古界）**：埕北310 沿井 XZ/YZ 剖面（振幅背景 + 密度/裂缝片/成像标签叠加，
   矿区尺度 + 井周局部）；
6. **验收**：每步 `summary.json` `status=pass`（范围/层窗/道映射/几何检查），
   最后更新交接文档。

## 6. 约束与风险

- 只有原始振幅：**不虚构**蚂蚁/相干/曲率特征；中/大尺度（Step6B/C、7B/C）本次不做；
- 成像井 TIME 为借用值：虚拟井样本须标记置信度，避免污染训练；
- 2 ms 密度体在 5 km×5 km 约 1.6 GB 量级（401×401 道 × 2500 样 × 4B），
  建议按道/分块流式处理，不整读入内存；
- 风化壳样本少（训练 2 井），小尺度模型需按地层分别报告验证指标；
- Step4 合并预测含重叠测次合并（等权），如发现振幅-密度不一致再回看权重方案。
