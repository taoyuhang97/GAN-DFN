# 太古界 Common 三属性合同修改方案

日期：2026-09-10  
适用范围：太古界 Step5 至 Step9 的 Coherence、AntTrack、CurvatureMax 属性读取与评分。

## 1. 本次要解决的问题

当前公共采样配置把 `AntTrack <= -0.99` 转换为缺失值。经与砂砾岩蚂蚁体口径复核，`-1` 不是文件缺失，而是“无/弱裂缝发育”的有效物理响应；蚂蚁体由 `-1` 向 `1` 增大时，裂缝证据增强。

若继续把 `-1` 变成 NaN，Step5 会错误降低虚拟井连续性，Step6A 会将低裂缝证据从训练和预测中删除，Step6B/6C 的评分口径也会与实际地质语义不一致。

## 2. 冻结的基础口径

- 三属性主网格以 CurvatureMax 的 `TraceIdx` 为准。
- 当前认为 Coherence、AntTrack、CurvatureMax 的道序一一对应；AntTrack 坐标约 1 m 的量化偏差暂不参与流程判定。
- 空间定位只做一次：`X/Y -> 最近属性主网格 TraceIdx`；三种体随后均以这个同一 `TraceIdx` 读取，禁止逐属性重复最近道搜索。
- 三属性统一使用绝对双程时间 `TIME(ms)`；属性文件索引时间按各自原始首样点平移到合同规定的绝对时间轴。
- 真正缺失仅包括 NaN、属性时间范围外、文件读取失败或主网格中不存在的道；蚂蚁体 `-1` 不是缺失。
- 正式目标窗口为：上部复合层 `Top <= TIME < Middle`；太古界风化壳 `Middle <= TIME < Bottom`。

## 3. Common 修改内容

### 3.1 属性读取

修改 `attribute_sampling.py` 与配置，删除 AntTrack 的 `invalid_le=-0.99` 规则。采样结果应保留 `AntTrackRaw=-1`。

公共接口输入为 `X, Y, TIME`，输出至少包含：主网格 `TraceIdx`、定位距离、三属性原始值与真实缺失标记。

### 3.2 即时归一化与评分

Common 只提供方法与小型参数合同，不保存全区三份归一化属性体。

- AntTrack：高值为高裂缝证据，`-1` 经评分为低分；
- Coherence：低值为高不连续/裂缝证据；
- CurvatureMax：高值异常为高裂缝证据。

归一化必须按目标层位分别计算稳健分位数，再裁剪映射到 `0-1`。原始属性值永不被归一化结果替换。

### 3.3 小型统计合同

流式遍历全区主属性网格及三界面层位合同，保存每层位、每属性的：有效样本数、NaN 数、AntTrack `-1` 数量、最小/最大值、P02/P05/P50/P95/P98、评分方向和实际裁剪阈值。

该合同只有少量 JSON/CSV 元数据，供 Step5/6A/6B/6C 即时计算使用，不产生额外全区体数据。

## 4. 验证要求

1. 三体道数、统一 TraceIdx 和时间轴通过检查；
2. 405 井附近、区域中心、边缘代表道均能读取三属性；
3. `AntTrack=-1` 保持有限原值，评分后为低值而非 NaN；
4. 三种证据分数都在 `0-1`；曲率/蚂蚁高值高分、相干低值高分；
5. 上部复合层和风化壳内均生成独立统计；
6. 不生成全区归一化属性体。

## 6. 2026-09-10 实施与验证记录

本次 Common 改造已完成并通过验证，尚未提交 GitHub：

- 公共采样器改为以 CurvatureMax 为唯一空间定位主网格，三体按同一 TraceIdx 读取；
- 删除 Common 配置中的 AntTrack `invalid_le=-0.99`；代码会主动拒绝仍携带该旧规则的调用配置，避免静默误用；
- 新增即时评分函数和分层小型归一化合同，不生成全区归一化体；
- 三体均为 2,156,550 道，合同时间范围均为 1800–4800 ms；
- demo 目标层位时间范围为 1958.4–4029.1 ms，三体均完整覆盖；
- 分层抽样共检查 1,444 条道；上部复合层发现 116,665 个 AntTrack `-1` 样点，风化壳发现 61,937 个；这些样点全部作为有效低值保留；
- 代表点验证中 `AntTrack=-1` 的得分为 0，`AntTrack=1` 的得分为 1，NaN 仍保持 NaN；
- 三属性代表点得分均在 0–1 范围内；
- 正式小型合同与代表道 QC 文件合计约 12 KB。

Common 验证通过不代表下游已经修复。Step5 与 Step6A 现有配置仍携带旧 AntTrack 无效值规则，公共采样器将主动报错；必须在各自改造阶段删除旧规则，并从 Step5A/5B 开始重新生成数据。
