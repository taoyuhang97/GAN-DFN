## 2. Step2 v5（`step2_well_log_segments/build_taigu_regular_samples.py`）

### 2.1 取样窗口

- **成像井不再用 `imaging_strata_mask()` 的 TVD 区间当取样窗口**；与常规井统一：
  逐点用 (X,Y) 查层位网格得 Top/Mid/Base → 判定 `InHorizonLayer`；
  取样窗口 = `InHorizonLayer=1 的行` ∪ `甲方成像 TVD 区间内的行`（**并集**）。
- 段切分仍按 MD 连续性（一层多段时保持多段输出）。
- 甲方 TVD 区间只用于生成标记列，不再截断数据。

### 2.2 新增列（每行）

| 列 | 含义 |
|---|---|
| `InImagingInterval` | 该点 TVD 是否落在甲方成像解释区间内（来自 `step1/imaging_tvd_strata_contract.csv`） |
| `ImagingTVDMin` / `ImagingTVDMax` | 该井甲方成像区间（便于审计） |
| `InHorizonLayer` | 该点 TIME 是否落在 [Top, Base] 内 |
| `LayerGroupByHorizon` | 层位口径层属（上部复合层 / 太古界风化壳） |
| `LayerGroupByImaging` | 甲方成像口径层属 |
| `UseCase` | `both` / `imaging_only` / `layer_only` / `none`（由前两列派生） |

### 2.3 元数据与审计

- `taigu_step2_well_metadata.csv` 增加每口成像井：
  `ImagingIntervalMDMin/Max`、`HorizonLayerMDMin/Max`、`BothRows`、`ImagingOnlyRows`、`LayerOnlyRows`；
- 新增 `taigu_step2_imaging_window_audit.csv`：逐井列出四块的 MD/TVD/TIME 边界与行数。

### 2.4 v4 已完成的，不要回退

轨迹来源优先级（甲方直井 → 井斜文件 → PRN → 直井）、方位角约定修正
（`dX=sin(DEV)·sin(AZIM)`、`dY=sin(DEV)·cos(AZIM)`）、起点用井口坐标锚定、
405 使用 `补充井位曲线-20260709/CBGX405.prn`、区外 5 口成像井按直井处理、

### 4.2 验证（折外，照砂砾岩）

- 该专家 ≥2 口标签井 → **leave_one_well_out**；只有 1 口 → **single_well_depth_block**（配置 `single_well_validation_blocks=5`）。
- 车页1导眼既进训练（LLD/LLS 唯一标签井），也用"单井 5 个深度块折外"做验证。

太古界 v5 采用：

1. **主验证 = 现有 LOO**：Step4 的 `train_validation_for_strata()` 已经按井留出——
   留出 405 时，用它以外的 5 口成像井（310/313/816/169/102）训练，再在 405 上预测。
   这一段 OOF 预测正好覆盖 ①+②，可用于"预测 vs 成像真值"对比，且是折外的。
   （现有 v4 产物已有这条折：`validation/direct_expert_validation_metrics.csv` 里
   `HeldOutWell=埕北古斜405`，5785 行；`validation/oof_predictions.csv` 为逐行折外预测。）
2. **补充验证（可选）= 单井深度分块**：把 405 的成像段按 TIME 切成 5 块，
   轮流留出一块、其余参与训练，拼出完整折外预测。用于"不整口留出 405"的对照口径。

## 9. 风险与注意

1. **借用时深**：405 用 CBGX22 的时深（4.4 km 外），"成像段超出层顶 35 ms"这个结论依赖它；
   用户已决定以 PRN + 借用时深为准，v5 不改时深，只在审计里留痕。
2. **NaN 与 0 的差别**：我们记 NaN（不参与训练），砂砾岩记 0（当负样本）；
   Step4/5 的样本门控必须按 NaN 处理，不能隐式填 0。
3. **区外 5 口成像井**：仍不进 Step5/6（属性覆盖之外），只用于 Step4 监督与产状统计。
4. **一层多段**：405 在 Step2 仍可能输出多段（不同测次），下游合并口径沿用现有的
   "同井合并 + 重叠按日期择一"。
