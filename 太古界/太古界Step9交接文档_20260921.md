### 5.2 改动细节

#### (a) 成像产状视倾角修正（`48d8df5`）

- 新增 `apparent_dip_trace(azimuth_deg, dip_deg, projection)`：法向 `n=(sinα·sinδ, cosα·sinδ, cosδ)`，交线 `t = n × 剖面法向`（XZ 用 `ŷ`、YZ 用 `x̂`），统一朝下，返回 `(dh_m, dt_ms)`。
- `imaging_patch_segments` 与 `imaging_orientation_ticks` 改用它。旧实现取"倾向矢量去掉视线分量"，投影后不在裂缝面内，会把陡缝压成近水平线。
- 405 的 312 个成像点实测：XZ 视倾角中位 21.6° → **51.6°**、YZ 8.4° → **73.6°**；与闭式公式 `tanβ=|sinα|·tanδ`(XZ) / `|cosα|·tanδ`(YZ) 逐点最大差 **0.000000°**。
- 依据：405 的甲方 LAS 参数块写明 `TLFamily_Azimuth = True Dip Azimuth`（真倾向）、`TLFamily_Dip_TRU = True Dip Inclination`。

#### (b) DFN 片迹线修正（`552267f`）

- `patch_segments` 改为走 `apparent_dip_trace`。**注意两套方位语义**：Step7/Step8 的 `AzimuthDeg` 是**走向**（0–180，VTK 几何也按走向建面），需 `+90°` 转成倾向方位；成像的 `FracAzimuth` 本身就是**真倾向方位**。
- 旧实现 `vertical = tan(dip)·max(|lateral|, 0.08)`：归一化后斜率恒等于真倾角，且走向接近垂直剖面时被直接拉成竖直。
- 局部 200 m XZ 屏角 >60° 的 DFN 段数 7 → 0。

#### (c) 纵向范围逐剖面自适应（`654188f`，配置 v7）

- 旧口径（v6 及以前）：`times` 在 `main()` 只算一次，取**全工区**层位合同的 `min(TopTimeMs)`~`max(BaseTimeMs)` ± `time_padding_ms(20)`，`overview` 与 `local_200m` 四个剖面共用 → 局部图纵向被压 6.86 倍、层位带只占图高 24–26%。
- 新口径：每个 scope 用**该剖面自己画出来的三条层位曲线**（Top/Mid/Base）的 min/max ± `scope_time_padding_ms`（=100 ms，即"方案 B"）；`local_200m` 取 `overview` 采样网格的行子集（两者都对齐 `section_sample_interval_ms`），属性/OBN 仍只采样一次。

| | v6 | v7 / v8 |
|---|---|---|
| overview 纵向范围 | 2604–4018 ms（1414） | 2606–3990 ms（1384） |
| local_200m 纵向范围 | 2604–4018 ms（1414） | **2750–3322 ms（572）** |
| 局部层位带占图高 | 26% / 24% | **65% / 58%** |
| 局部纵向压缩 | 6.86 倍 | **2.7 倍** |
| 全局纵向压缩 | 0.98 倍 | **≈1.0 倍（近似等比例）** |

- summary 新增 `time_range_ms_by_scope` 与 `time_window_policy`。

#### (d) 叠加层顺序改造 + 成像井段轨迹（`39ad892`，配置 v8）

- `patch_segments` 增加第 5 个返回值 `crossed: list[bool]`：按片的走向/倾角算它在剖面法向（XZ→Y、YZ→X）上的半宽
  `half·|sinθ|(XZ) / |cosθ|(YZ) + half_dip·|cosθ|(或 |sinθ|)`，其中 `half_dip = HeightTimeMs/tan(dip)`（米）；片中心到该剖面距离 < 半宽即判为"剖面真实切到"。
- 绘制分层：真实交线 zorder **12.9（大尺度描边）/ 13.1（线）**；井周投影片 zorder **12.7**、alpha 0.42、线宽 ×0.85；图例新增 `DFN裂缝片：井周投影（半透明）`。
- 新增青色"成像测井段轨迹"：用 `track` 中 `InImagingInterval==1` 的行，zorder 12.5/12.55（压在井轨迹 12.4/12.45 之上），label `埕北古斜405成像测井段轨迹`。
- 实测 v8（局部 200 m）：XZ 画 3036 条 DFN 段（**真实交线 527** / 井周投影 2509）；YZ 3102 条（**336** / 2766）。summary 每张图 `overlay` 新增 `dfn_crossed_count` / `dfn_projected_count`。

## 8. 已尝试但失败的方案 / 不要重复踩的坑

1. **不要用 Step8 CSV 里的 `V1X..V4Z` 顶点做几何**。实测它们与 `DipDeg/AzimuthDeg` 不一致：
   - 四边形长边方位 = `90° − AzimuthDeg`（把方位角当成"自东逆时针"的数学角，8/8 抽样完全吻合）；
   - 短边满足 `tan(几何倾角) = 2 × tan(DipDeg)`（全量中位比值正好 2.00）。
   因此"照搬砂砾岩的真实几何求交"在太古界会画出错误几何。修这两个顶点错误属于 Step7/Step8 层的问题，本轮未动。
2. **不要把 405 成像点的 TVD 映射当成 bug**。甲方点文件列名是 `TDEP`，实测其范围（3676.8–3998.9）恰好等于该井在 MD 4104.7–4558.9 上的 TVD 范围，且甲方解释成果图文件名就是"…(3676.7-4000.0m)"。结论：`TDEP` 在该交付里等价于 TVD，Step3 按 TVD 回接是**正确**的，不要"修正"成 MD。
3. **不要用肉眼判断 PNG 角度**。局部剖面早期纵向压缩 6.86 倍，任何非接近真垂直的线都会被压平；判断前先用坐标轴刻度做 px↔m/ms 标定。另外叠加层多为半透明（alpha 0.42–0.95），按"精确 RGB"取色会漏检，需按色相/背景宽容度取色。
4. **不要试图全量读 2 GB 级 CSV**，用统计量/抽样。
5. **配置里路径要小心**：新增 v7 配置时曾把 `original_fault_vtk` 误写成 `.tif`，靠 `--validate-only` 立刻发现并改回 `.vtk`。
6. **`git push` 可能卡在 SSH 连接上**（本轮第一次挂在 `ssh git@github.com git-receive-pack` 超过 4 分钟无输出）。commit 已完成，直接 kill 掉挂起的 push 进程后重试即可（重试秒过）。

## 11. 已知风险、坑、限制

1. **版本后缀混乱**：commit message 与配置/产物后缀不是一套编号。查证时以**配置文件名与输出目录名**为准。

   | 提交 | 提交信息里的后缀 | 对应配置/产物 |
   |---|---|---|
   | `48d8df5` | v8 | 仍是 v6 配置（成像产状修正） |
   | `552267f` | v9 | 仍是 v6 配置（DFN 迹线修正） |
   | `654188f` | v7 | **v7 配置**（纵向自适应） |
   | `39ad892` | v8 | **v8 配置**（叠加层顺序） |

2. **DFN 3D 几何不可信**：Step8 输出的 `V1..V4` 顶点有走向镜像 + 倾角 2× 放大两处错误，ParaView 里看到的 DFN 与 CSV 字段不一致；任何"按几何出图/求交"的方案都先要修这两处。
3. **局部剖面是"投影"而非"切片"**：`local_dfn_projection_half_width_m=200` 意味着剖面显示的是井周 ±200 m 薄板内所有片的投影，不是严格切片；真交线只占 11–17%，其余是投影（v8 已用半透明区分）。
4. **剖面是弯曲剖面**：XZ 剖面取 `(x, Ywell(t), t)`、YZ 取 `(Xwell(t), y, t)`，随井轨迹弯曲；层位曲线用固定点迭代求解（8 次），与砂砾岩的 12 次迭代实现不同。
5. **405 是斜井**：成像段水平位移 498.9 m、井斜约 41°（X 跨度 350 m、Y 跨度 355 m，方向 44.6°），所以 XZ 与 YZ 上井形几乎一样（正常现象）；也因此局部剖面横向必须铺 738 m。
6. **成像段与层位不完全重合**：405 成像区间 MD 4104.7–4557.8，其中 75 m（至 4180.2）在"上部复合层顶"之上；最深成像点在 MD 4555.0，距太古界顶仅 3.8 m——这是甲方 FMI 解释段本身的下限（TVD 4000.0 m）造成的，不是放错位置。
7. **砂砾岩的 DFN 剖面用真实几何求交、太古界用字段解析**：两者不可直接对比；在太古界几何修好之前，不要用"几何求交"结果去质疑字段结果。
8. **区外井的层位是外推的**：太古界区外 5 口井到层位网格 1.3–10.2 km（405 仅 5 m，可靠）；Step5 已核实无区外井误构造虚拟井。
9. **输出目录不入库**（`.gitignore` 已忽略 `**/output/`、`太古界/output_*_logs/`），产物只在本地。
