# 太古界常规测井与成像测井数据使用说明

更新时间：2026-08-07

## 1. 目的与范围

本文记录太古界地区“常规测井裂缝预测”数据构造所使用的数据、坐标口径、已确认限制和待核验事项。

当前范围仅覆盖：

- `common`：DLIS 与曲线目录公共工具；
- `step1_strata_contracts`：时间层位、时深和成像解释 TVD 界面合同；
- `step2_well_log_segments`：常规测井 MD/TVD/GR/RD/RS 底板；
- `step3_imaging_groups`：成像连续裂缝密度和裂缝点位监督标签；
- `step4_fracture_prediction`：基于 GR/RD/RS 的裂缝预测。

本文不将不同井、不同解释口径的裂缝密度静默合并为同一个真值。

## 2. 坐标与深度域原则

### 2.1 常规测井

常规测井样点原始深度使用 LAS 中的 `MD`（或 `DEPT`）。其地层归属路径固定为：

```text
LAS MD -> 本井时深曲线 -> TIME -> 时间层位面 -> 时间区间/StrataName
```

规则：

- 只允许使用本井时深文件；
- 缺少本井时深文件的常规井直接排除，不复用其他井时深；
- 时深曲线范围外的 MD 不外推；
- 时深曲线大空缺不跨越插值；
- 常规测井最终用于首版模型的基础字段为 `MD/GR/RD/RS`。

时深文件目录：

```text
/data/shared/project-oil/wx数据/埕岛太古界/时深
```

### 2.2 成像测井

当前所有成像测井井缺少可用时深文件。因此成像测井不能通过时间层位面划分地层，也不能借用常规井时深关系。

成像测井地层归属路径固定为：

```text
成像解释成果中的 TVD 地层界面 -> 成像常规测井 TVD 样点 -> StrataName
```

成像井应从其解释成果中提取实际覆盖段的层位归属及实际出现的 TVD 分界面，并单独保存来源和人工核验状态。解释段全部属于单一地层时，只记录该地层归属，不为未出现的界面补造 TVD 数值。

深度语义（2026-08-12 确认）：成像解释成果（解释段上下界、密度/裂缝点位深度、313 窗口）
一律为 **TVD（真实垂向深度）**；LAS 的 DEPT 为 **MD（沿井测深）**。两者通过每口井的
轨迹（井斜文件 > LAS DEV/AZIM 积分 > 直井回退）逐行转换，Step2 输出同时携带
`MD/TVD/X/Y/TIME`。

### 2.3 井点坐标

坐标统一使用投影坐标：X 为横坐标（Easting，米），Y 为纵坐标（Northing，米），
与 `参与井井头信息.dat` 及层位文件坐标口径一致。

来源说明：

- 常规井坐标来自 `参与井井头信息.dat`（25 口），2026-08-12 确认采用；
- 成像井坐标来自项目成员于 2026-08-12 提供。现有机器可读数据中无成像井坐标
  （LAS ~W 段无 X/Y 字段、XX/YY 曲线未填充、测井信息表无坐标、井斜目录只覆盖
  部分常规井）；埕北39 无井点坐标；

## 4. 时间层位文件

层位目录：

```text
/data/shared/project-oil/wx数据/埕岛太古界/层位
```

当前确认的三个界面由上至下为：

```text
Grid_上部复合层T-a-1.dat
Grid_太古界顶Art_1.dat
Grid_风化壳底Art_d1-1.dat
```

其角色固定为：

| 层位文件 | 角色 |
|---|---|
| `Grid_上部复合层T-a-1.dat` | 处理区域上边界 |
| `Grid_太古界顶Art_1.dat` | 处理区域内部拆分界面 |
| `Grid_风化壳底Art_d1-1.dat` | 处理区域下边界 |

两个处理区域及其时间域判定为：

```text
上部复合层：TopTime <= TIME < MiddleTime

```

`Grid_太古界顶Art_1.dat` 的作用类似砂砾岩地区的 T6 层位：它不是处理区域外边界，而是将处理区域拆成裂缝发育规律不同的上、下两个建模区域。

### 5.2 成像井监督底板

目录：

```text
/data/shared/project-oil/wx数据/埕岛太古界/侧向电阻率曲线/成像测井/RD
```

用途：为有可靠成像解释的井读取对应 LAS。成像监督样本仍以 LAS 原始 `MD/GR/RD/RS` 样点为底板；地层通过成像解释的 MD 界面标注。

### 5.3 LAS 使用规则

- 同井多 LAS 文件按 MD 覆盖和 `GR/RD/RS` 完整度分段选择；
- 重叠区不对曲线简单平均；
- 保留原始有效数值；
- `-999.25`、`-9999`、`-99999` 等明确无效值转换为缺失；
- 不跨越明显大空缺插值；
- 预测模型不对缺少完整 `GR/RD/RS` 的样点填零。

## 6. 成像裂缝解释与监督标签

裂缝解释来源和统计范围的权威汇总文件：

```text
/data/shared/project-oil/wx数据/埕岛太古界/太古界测井信息.xlsx
```

工作表：`成像测井裂缝解释结果`。

监督样本字段：

```text
Density
HasFractureDensity = Density > 0
GT_POINT_FLAG
Frac_Azimuth
Frac_Dip
DensityKind
FractureScope
DensitySourcePath
PointSourcePath
```

规则：

- `Density` 是连续主标签；
- `HasFractureDensity` 只是辅助二值标签；
- `GT_POINT_FLAG` 是实际裂缝点位映射结果，不能替代 `Density`；
- 零密度是有效标签；缺测、超出密度覆盖范围和无法可靠插值的位置必须保留 `NaN`，不能写为零；
- 密度插值只能发生在原始密度有效覆盖范围内，且两端深度间隔不超过配置阈值；
- 点位只允许映射到距离足够近的 LAS TVD 样点，超出容差时记录为未映射。

## 7. 样本构造职责

```text
Step1
  常规井：本井 MD -> TIME -> 时间层位合同
  成像井：解释成果的 MD 层位归属与实际界面合同
    ↓
Step2
  常规 LAS -> MD/GR/RD/RS 底板 -> 按相应层位合同裁剪
    ↓

  成像井常规底板 + 连续密度 + 裂缝点位 -> 监督样本与 QC
    ↓

  使用通过 QC 的监督样本训练 GR/RD/RS 裂缝预测模型
```
