# 专家模型库可用性说明

## 1. 文档目的

本文档用于说明当前“分地层专家模型库 + 两阶段裂缝预测流程”的定位、可用边界、验证结果与后续建议，供项目内部协作和对外沟通统一口径使用。

当前说明聚焦的是第一部分中的后两步：

- 第一步结果：常规测井裂缝发育段预测
- 第二步结果：基于发育段的裂缝点位细化

本文档不把当前模型描述为最终生产方案，而是明确说明其当前能做到什么、还做不到什么。

## 2. 当前流程定位

当前整体思路是：

1. 先按地层切分目标井段
2. 在每个地层内，基于地震属性与常规测井属性的相似性选择最接近的成像井专家模型
3. 用对应的第一阶段模型预测候选裂缝发育段
4. 用对应的第二阶段模型或规则对候选裂缝发育段进行点位细化
5. 将各地层结果拼接成整井结果
6. 用原始离散裂缝标注对整井和分层结果做外部验证

这里的“专家模型库”不是单一模型，而是按地层、按井段组织的候选模型集合。

## 3. 当前结论

当前专家模型库`可以作为解释辅助工具使用`，但`还不能作为最终自动定量预测工具直接投入应用`。

更具体地说：

- 第一阶段结果可以用于`候选裂缝发育段筛选`
- 第二阶段结果可以用于`候选裂缝点位趋势参考`
- 当前整套流程可以用于`研究验证`与`人工解释辅助`
- 当前整套流程还不适合直接输出`最终裂缝条数`、`最终裂缝点位`或`最终 DFN 输入`

## 5. 为什么当前只能作为辅助解释工具

当前流程已经具备“筛选可疑裂缝区间”的能力，但还不具备“稳定恢复真实裂缝条数和精确点位”的能力，主要原因包括：

- 第一阶段在不同井、不同层之间的泛化差异仍然较大
- 第二阶段对裂缝点数的恢复不稳定，常表现为明显偏少
- 跨层井验证说明，整井应用时还会叠加分层切分、分层选模、结果拼接带来的额外误差
- 在弱井、弱层和样本稀疏层段上，当前专家模型库还缺乏足够稳定性

因此，当前输出更适合解释为：

- 哪里可能存在裂缝发育
- 哪些区间值得优先人工检查
- 当前目标井在哪个地层上更接近哪一口成像井的裂缝模式

## 6. 当前推荐使用方式

如果当前需要把专家模型库用于实际工作，建议采用“`辅助解释模式`”，不建议采用“`自动定量模式`”。

推荐使用流程：

1. 先按地层切分目标井段
2. 在地层内部计算目标井与候选成像井之间的属性相似度
3. 选择最接近的专家模型
4. 用第一阶段结果圈定候选裂缝发育段
5. 用第二阶段结果给出候选裂缝点位分布趋势
6. 由人工解释人员对结果进行审核和修正
7. 审核后的结果再进入后续倾向倾角分析或 DFN 构建

当前最稳妥的原则是：

- `第一阶段用于筛选`
- `第二阶段用于参考`
- `最终成果以人工校核为准`

## 7. 当前不建议直接使用的场景

当前专家模型库不建议直接用于以下工作：

- 直接输出某口常规测井的最终裂缝条数
- 直接输出某口常规测井的最终裂缝点位成果
- 不经人工审核直接作为 DFN 建模输入
- 用于精确对齐单条裂缝的真实位置
- 在弱井、弱层或样本不足层段上直接做自动定量解释

尤其不建议直接相信以下量化量：

- 预测裂缝总条数
- 点位数量与原始条数的一致性
- 单点级别的位置一一对应关系
